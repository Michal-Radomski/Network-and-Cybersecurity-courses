**Crunch** is a command-line tool used in cybersecurity to **generate wordlists**—files containing large numbers of possible
passwords or strings.

### What it does

You specify things such as:

- **Minimum length** of generated strings
- **Maximum length**
- **Character set** to use
- Optionally, a **pattern** that controls where characters appear
- Whether to generate output incrementally

For example:

```
crunch 4 4 abcd
```

generates every 4-character combination using `a`, `b`, `c`, and `d`.

The output can be redirected to a file:

```
crunch 4 4 abcd -o wordlist.txt
```

### Common options

- `-o` — write the generated wordlist to a file
- `-i` — use **incremental mode**
- `-t` — specify a **pattern** for the generated strings
- `-f` — use a specified character set from Crunch's character-set file
- `-p` — generate permutations of supplied words/characters

Crunch is commonly used for **authorized password auditing, penetration testing, and security labs**. Its output can become
enormous very quickly, so the length and character set have a major impact on the resulting file size.
