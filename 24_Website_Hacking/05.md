## OWASP ZAP

OWASP ZAP (**Zed Attack Proxy**, or **ZAP**) is a free, open-source tool for **testing the security of web applications**.

It sits between your browser and a web application as a **proxy**, allowing you to inspect and modify HTTP/HTTPS requests and
responses.

### What ZAP can do

- **Intercept requests** — see exactly what your browser sends to a website.
- **Inspect responses** — examine headers, cookies, HTML, and other data returned by the server.
- **Modify requests** — useful for testing how an application handles unexpected or manipulated input.
- **Spider/crawl websites** — discover pages and endpoints.
- **Passive scanning** — identify potential security issues while traffic passes through ZAP.
- **Active scanning** — send specially crafted requests to test for vulnerabilities such as injection and insecure
  configurations.
- **Fuzzing** — test parameters with many different inputs.
- **API testing** — work with REST and other web APIs.

### Basic workflow

A typical authorized security-testing workflow is:

```
Browser
   ↓
  ZAP
   ↓
Web application
```

You configure your browser to use ZAP as its proxy. When you visit the application, ZAP records the traffic, giving you a
view such as:

```
GET /login HTTP/1.1
Host: example.test
Cookie: session=...
```

You can then inspect the request, send it to other ZAP tools, and analyze the application's behavior.

### ZAP vs. Hydra vs. Crunch

| Tool          | Main purpose                                           |
| ------------- | ------------------------------------------------------ |
| **Crunch**    | Generates wordlists                                    |
| **Hydra**     | Tests authentication by trying credential combinations |
| **OWASP ZAP** | Tests and analyzes web applications                    |

So, in a penetration-testing workflow, they can serve very different roles: **Crunch creates candidate inputs → Hydra tests
network authentication → ZAP analyzes web applications and their HTTP traffic.**

Use ZAP's active scanning and fuzzing only against applications you own or have explicit permission to test.
