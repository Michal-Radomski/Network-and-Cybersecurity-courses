Here is how to implement the **Synchronizer Token Pattern** using TypeScript for a Node.js/Express backend and a React
frontend.

In this pattern, the server generates a cryptographically secure token, sends it to the client (usually via a readable cookie
or a dedicated endpoint), and the client must echo that token back in a custom header for any state-changing request (POST,
PUT, DELETE).

---

### Backend: Node.js & Express CSRF Middleware

In this example, we generate a CSRF token using the built-in `crypto` module, set it in a non-HttpOnly cookie (so JavaScript
can read it), and create middleware to validate it on protected routes.

```typescript
import express, { Request, Response, NextFunction } from "express";
import cookieParser from "cookie-parser";
import crypto from "crypto";

const app = express();
app.use(express.json());
app.use(cookieParser());

// Endpoint to provide the CSRF token to the client on initial load
app.get("/api/csrf-token", (req: Request, res: Response) => {
  const csrfToken = crypto.randomBytes(32).toString("hex");

  // Store token in a cookie (non-httpOnly so frontend JS can read it)
  res.cookie("XSRF-TOKEN", csrfToken, {
    secure: process.env.NODE_ENV === "production",
    sameSite: "strict",
    maxAge: 1000 * 60 * 60 * 24, // 24 hours
  });

  res.json({ csrfToken });
});

// CSRF Protection Middleware for state-changing requests
const csrfProtection = (req: Request, res: Response, next: NextFunction) => {
  // Skip check for safe methods
  if (["GET", "HEAD", "OPTIONS"].includes(req.method)) {
    return next();
  }

  const tokenFromCookie = req.cookies["XSRF-TOKEN"];
  const tokenFromHeader = req.headers["x-csrf-token"];

  if (!tokenFromCookie || !tokenFromHeader || tokenFromCookie !== tokenFromHeader) {
    return res.status(403).json({ error: "Invalid or missing CSRF token" });
  }

  next();
};

// Apply middleware to sensitive routes
app.post("/api/update-profile", csrfProtection, (req: Request, res: Response) => {
  // Perform state-changing action safely here
  res.json({ message: "Profile updated successfully" });
});
```

### Frontend: React & Axios Interceptor

On the React side, you fetch the CSRF token when the app initializes (or extract it from the cookie if readable), and
configure an Axios request interceptor to automatically attach it to the `X-CSRF-Token` header for all mutation requests.

```typescript
import axios from "axios";

export const api = axios.create({
  baseURL: "https://api.example.com",
  withCredentials: true, // Required to send/receive cookies
});

// Helper function to read a cookie by name on the client side
const getCookie = (name: string): string | null => {
  const value = `; ${document.cookie}`;
  const parts = value.split(`; ${name}=`);
  if (parts.length === 2) return parts.pop()?.split(";").shift() || null;
  return null;
};

// Request Interceptor: Attach the CSRF token to state-changing requests
api.interceptors.request.use(
  (config) => {
    const method = config.method?.toUpperCase();

    // If it's a mutation request, attach the token from the cookie
    if (["POST", "PUT", "DELETE", "PATCH"].includes(method || "")) {
      const csrfToken = getCookie("XSRF-TOKEN");
      if (csrfToken) {
        config.headers["X-CSRF-Token"] = csrfToken;
      }
    }

    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);
```
