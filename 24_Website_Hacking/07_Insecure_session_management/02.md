Here are TypeScript code snippets demonstrating secure session management using an Express backend with HTTP-only cookies and
a React frontend configured to send credentials securely.

---

### Backend: Node.js & Express Session Setup

In this Express configuration, cookies are locked down with strict security flags to prevent XSS and CSRF attacks.

```typescript
import express, { Request, Response } from "express";
import session from "express-session";

const app = express();

app.use(
  session({
    secret: process.env.SESSION_SECRET || "fallback_secret_key",
    resave: false,
    saveUninitialized: false,
    cookie: {
      httpOnly: true, // Prevents client-side JS from reading the cookie (protects against XSS)
      secure: process.env.NODE_ENV === "production", // Ensures cookie is only sent over HTTPS in production
      sameSite: "strict", // Blocks cookie from being sent on cross-site requests (protects against CSRF)
      maxAge: 1000 * 60 * 60 * 24, // Session expires in 24 hours
    },
  })
);

app.post("/api/login", (req: Request, res: Response) => {
  // Assume authentication passes here
  // Regenerate session ID upon login to prevent session fixation attacks
  req.session.regenerate((err) => {
    if (err) return res.status(500).json({ error: "Server error" });

    // Store user info in session
    (req.session as any).userId = "user_12345";
    res.json({ message: "Logged in successfully" });
  });
});
```

### Frontend: React API Client Setup

When making requests from a React application, you must explicitly configure your HTTP client to include credentials so the
secure cookie is attached automatically.

```typescript
import axios from "axios";

// Create a reusable Axios instance
const apiClient = axios.create({
  baseURL: "https://api.example.com",
  withCredentials: true, // Crucial: ensures browser sends the session cookie with requests
});

export const fetchUserProfile = async () => {
  try {
    const response = await apiClient.get("/api/user/profile");
    return response.data;
  } catch (error) {
    console.error("Failed to fetch profile", error);
    throw error;
  }
};
```
