If you started the **Browser Exploitation Framework (BeEF)** in a terminal, press:

```
Ctrl+C
```

That normally stops the running BeEF process.

If it was started in the background, find its process:

```bash
ps aux | grep -i '[b]eef'
```

Then terminate the specific process:

```bash
kill <PID>
```

If you launched it as a system service, check:

```bash
systemctl status beef
```

and, if it is actually registered as a service:

```bash
sudo systemctl stop beef
```

Avoid using `kill -9` unless the normal `kill` doesn't work.
