Using **React Router** is a great choice. Its built-in hooks (like `useSearchParams` and `useParams`) make handling URL
parameters much cleaner and safer than parsing raw strings from `window.location` manually.

### Why React Router Helps with Security

- **Structured Parsing:** Hooks like `useSearchParams()` extract parameters safely without requiring you to manually slice or
  manipulate the raw URL string.
- **JSX Integration:** When you pass these parameters directly into JSX elements (`{searchParams.get('q')}`), React
  automatically escapes them, protecting you against DOM-based XSS by default.

Just remember the golden rule: as long as you stick to standard JSX rendering, you're protected. Only bring in a sanitizer
like DOMPurify if you ever need to render router parameters as raw HTML.
