**Burp Proxy** and **Burp Suite** are not the exact same thing, but they are closely related.

- **Burp Suite** is the overarching platform and toolkit used for web application security testing. It contains a collection
  of many different tools.
- **Burp Proxy** is one specific tool _inside_ Burp Suite.

### How They Relate:

Think of Burp Suite as a Swiss Army knife, and Burp Proxy as one of the individual blades.

- **Burp Proxy** acts as an intercepting proxy server sitting between your web browser and the target application. It lets
  you view, modify, and drop HTTP/HTTPS requests and responses in real-time.
- **Burp Suite** bundles this proxy along with many other powerful tools, such as:
- **Repeater:** For modifying and resending individual HTTP requests repeatedly.
- **Intruder:** For automating custom attacks, fuzzing, or brute-forcing parameters.
- **Decoder:** For encoding and decoding data (like Base64, URL encoding, or hashes).
- **Scanner:** (In professional editions) For automatically finding vulnerabilities.

In short, you launch **Burp Suite** to access **Burp Proxy** along with the rest of the testing utilities.
