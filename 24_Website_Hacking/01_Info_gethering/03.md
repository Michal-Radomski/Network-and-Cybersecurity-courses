Discovering other websites hosted on the same server and finding hidden subdomains are key parts of the reconnaissance phase.
Here is how pentesters approach these two techniques:

---

### 1. Discovering Websites on the Same Server (Reverse IP Lookup)

When multiple websites share a single IP address (common with shared hosting or certain cloud environments), a **Reverse IP
lookup** allows pentesters to find all the other domain names pointing to that same server.

- **How it Works:** Instead of looking up a domain to find its IP address, the query searches DNS databases in reverse—taking
  a known IP address and listing every domain associated with it.
- **Common Tools & Services:** Online databases like **ViewDNS.info** or **SecurityTrails** let researchers run reverse IP
  lookups instantly. Pentesters can also use network tools like **Nmap** (`http-стрим` or hosting enumeration scripts).
- **Why it Matters:** If a target organization owns multiple domains or if a shared server hosts a vulnerable secondary site,
  it can provide an alternative, less-defended entry point into their infrastructure.

---

### 2. Discovering Subdomains

Subdomains (such as `login.example.com`, `api.example.com`, or `staging.example.com`) frequently point to secondary
applications, testing environments, or administrative portals that may lack the security hardening of the main website.

Pentesters use a combination of passive and active techniques to map them out:

- **Certificate Transparency (CT) Logs:** Every time a public Certificate Authority issues an SSL/TLS certificate, it gets
  logged in a public database (like `crt.sh`). Pentesters query these logs to see every subdomain a company has requested
  certificates for in the past.
- **DNS Brute-Forcing:** Using tools like **Gobuster**, **Amass**, or **Sublist3r**, pentesters run through massive wordlists
  of common subdomain prefixes (like `dev`, `test`, `internal`, `vpn`) and ask the target's DNS server if they exist.
- **Search Engine and Aggregator APIs:** Querying threat intelligence platforms and search engines (such as Shodan,
  VirusTotal, or Censys) that continuously crawl the web and index discovered subdomains.
