## Preventing Code Execution Vulnerabilities in Node & React

Code execution vulnerabilities (such as Remote Code Execution, or RCE) happen when an application improperly handles user
input and executes it as system commands or compiled code. Here is how you can secure your full-stack application using
TypeScript.

---

### 1. Secure Node.js Backend Execution

The primary risk in Node.js comes from unsafe evaluation or spawning shell processes with untrusted data.

- **Never use `eval()` or `new Function()**` with user-supplied data.
- **Avoid `child_process.exec()**` when user input is involved, as it runs commands inside a shell and leaves you open to
  injection.
- **Use `child_process.execFile()` or `spawn()**` instead, which passes arguments as a strict array rather than a
  concatenated string.

```typescript
import { execFile } from "child_process";

// UNSAFE: Vulnerable to command injection if userInput contains shell characters
// exec(`ping ${userInput}`);

// SAFE: Arguments are passed as an array, preventing shell injection
export function runSafeCommand(userInput: string): void {
  // Validate or whitelist userInput here before passing it
  const safeArgs = [userInput];

  execFile("/sbin/ping", safeArgs, (error, stdout, stderr) => {
    if (error) {
      console.error(`Execution error: ${error.message}`);
      return;
    }
    console.log(`Output: ${stdout}`);
  });
}
```

---

### 2. Protect Your React Frontend

React escapes values rendered inside JSX by default to mitigate Cross-Site Scripting (XSS), but insecure patterns can still
introduce risks.

- **Avoid
  `dangerouslySetInnerHTML**`unless strictly necessary. If you must use it, sanitize the HTML string first using a trusted library like`DOMPurify`.
- **Validate URLs** before passing them into elements that trigger execution, such as `javascript:` protocol links in anchor
  tags (`<a href="...">`).

```typescript
import DOMPurify from 'dompurify';

interface SafeHTMLProps {
  rawHtml: string;
}

export const SafeComponent: React.FC<SafeHTMLProps> = ({ rawHtml }) => {
  // Sanitize the HTML to prevent malicious script injection
  const cleanHtml = DOMPurify.sanitize(rawHtml);

  return <div dangerouslySetInnerHTML={{ __html: cleanHtml }} />;
};

```
