Here is how a Local File Inclusion (LFI) vulnerability happens in an **Express.js** application using **TypeScript**, along
with how to fix it securely.

---

### 1. The Vulnerable Code (Insecure)

In this example, the user passes a file name via the query parameter (`?file=about.html`). Because the input is concatenated
directly into the file system path without validation, an attacker can input `../../etc/passwd` to traverse directories.

```typescript
import express, { Request, Response } from "express";
import fs from "fs";
import path from "path";

const app = express();

// VULNERABLE ENDPOINT
app.get("/view", (req: Request, res: Response) => {
  const fileName = req.query.file as string;

  // Danger: Directly concatenating user input allows path traversal (LFI)
  const filePath = path.join(__dirname, "public", fileName);

  fs.readFile(filePath, "utf8", (err, data) => {
    if (err) {
      return res.status(404).send("File not found");
    }
    res.send(data);
  });
});
```

---

### 2. The Secure Fix (Protected)

To prevent LFI, you must ensure that the resolved file path stays strictly within the intended directory, or better yet, use
a **whitelist** of allowed files.

#### Approach A: Strict Whitelisting (Recommended)

Only allow specific, predefined files to be loaded.

```typescript
import express, { Request, Response } from "express";
import fs from "fs";
import path from "path";

const app = express();

// Define a strict whitelist of allowed files
const ALLOWED_FILES: Record<string, string> = {
  about: "about.html",
  contact: "contact.html",
  home: "index.html",
};

app.get("/view-safe", (req: Request, res: Response) => {
  const page = req.query.page as string;

  // Check if the requested page exists in our whitelist
  if (!page || !ALLOWED_FILES[page]) {
    return res.status(400).send("Invalid or unauthorized file request.");
  }

  const safeFileName = ALLOWED_FILES[page];
  const filePath = path.join(__dirname, "public", safeFileName);

  fs.readFile(filePath, "utf8", (err, data) => {
    if (err) {
      return res.status(404).send("File not found");
    }
    res.send(data);
  });
});
```

#### Approach B: Path Traversal Check (`path.resolve` + `path.relative`)

If dynamic filenames are required, verify that the resolved path still starts with the target directory.

```typescript
app.get("/view-dynamic", (req: Request, res: Response) => {
  const fileName = req.query.file as string;
  const publicDir = path.join(__dirname, "public");

  // Resolve the absolute path
  const filePath = path.resolve(publicDir, fileName);

  // Ensure the file path starts with the public directory path
  if (!filePath.startsWith(publicDir)) {
    return res.status(403).send("Access denied: Path traversal detected.");
  }

  fs.readFile(filePath, "utf8", (err, data) => {
    if (err) {
      return res.status(404).send("File not found");
    }
    res.send(data);
  });
});
```
