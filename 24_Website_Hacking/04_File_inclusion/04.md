## Preventing Remote File Inclusion (RFI) in Node.js & TypeScript

While RFI is historically tied to languages like PHP (via unsafe include functions), Node.js applications can face a similar
risk if user input controls external URLs passed into HTTP fetchers or template engines, which might then be evaluated or
executed.

To protect your application, you must **never** let user input dictate remote URLs without strict validation, and never
execute or evaluate remote content as code.

---

### Secure URL Validation and Fetching

If your application needs to retrieve resources or data from external sources based on user input, you should:

1. **Parse the URL** using the built-in `URL` class to safely inspect its components.
2. **Enforce a strict whitelist** of approved domains.
3. **Restrict protocols** (e.g., allow only `https:` and disallow dangerous protocols like `file:` or `ftp:`).
4. **Treat data as data only**—never pass fetched remote content into execution functions like `eval()` or template
   renderers.

```typescript
import express, { Request, Response } from "express";

const app = express();

// Define a strict whitelist of trusted external domains
const TRUSTED_DOMAINS = ["api.trusted-partner.com", "data.example.org"];

app.get("/fetch-resource", async (req: Request, res: Response) => {
  const targetUrl = req.query.url as string;

  if (!targetUrl) {
    return res.status(400).send("Missing URL parameter.");
  }

  try {
    // Parse the URL to safely inspect its properties
    const parsedUrl = new URL(targetUrl);

    // Enforce HTTPS and check against the domain whitelist
    if (parsedUrl.protocol !== "https:" || !TRUSTED_DOMAINS.includes(parsedUrl.hostname)) {
      return res.status(403).send("Access Denied: Untrusted domain or insecure protocol.");
    }

    // Safely retrieve the remote data as text or JSON (never execute it)
    const response = await fetch(parsedUrl.toString());
    const data = await response.text();

    res.status(200).json({ success: true, content: data });
  } catch (error) {
    res.status(400).send("Invalid URL format.");
  }
});
```
