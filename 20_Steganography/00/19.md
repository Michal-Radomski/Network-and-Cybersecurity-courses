## 📊 Method 2: Flattened Bit String (Easier for Small Files)

If you prefer to convert the entire file into a single string of '1's and '0's, you can map over the buffer. This is highly
intuitive but will consume more memory for large files.

import \* as fs from 'fs'; /\*\*
