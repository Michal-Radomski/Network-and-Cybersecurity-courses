An application determines whether an image is **Grayscale**, **RGB**, or **RGBA** by inspecting the image file's metadata
(headers) or by directly analyzing the pixel data stored within the file.

Here is a breakdown of how this process works behind the scenes:

---

### 1. Reading the Metadata (File Headers)

Most image formats (like PNG, JPEG, or WebP) contain a file header at the very beginning of the data stream. This header acts
like a label, telling software how to interpret the bytes that follow.

- **File Format Specifications:** Standards like PNG have specific chunks (such as the `IHDR` chunk) that explicitly state
  the **color type** (e.g., grayscale, truecolor RGB, or indexed color with alpha).
- **Instant Detection:** When an app opens the file, it reads these first few bytes and immediately knows the color space
  without needing to scan every single pixel.

---

### 2. Analyzing Pixel Channels

If an image format lacks explicit metadata or if the image has already been loaded into the device's memory as a raw bitmap,
the app looks at the **channels** per pixel. A channel is a single component of a color.

- **Grayscale (1 Channel):** \* Each pixel contains only **one value** representing light intensity (usually ranging from 0
  for black to 255 for white).
- **RGB (3 Channels):** \* Each pixel contains **three values**: **R**ed, **G**reen, and **B**. The combination of these
  three values creates a full spectrum of colors.
- **RGBA (4 Channels):** \* Each pixel contains **four values**: **R**ed, **G**reen, **B**, and **A**lpha. The alpha channel
  controls the transparency or opacity of that specific pixel.

---

### 3. Programmatic Check (Code Example)

When developers write code to check an image's type, they usually query the properties of the image object provided by a
programming library.

For example, in Python using the Pillow library:

```python
from PIL import Image

img = Image.open('example.png')

# img.mode returns 'L' for grayscale, 'RGB', or 'RGBA'
print(img.mode)

```

---

### Comparison of Image Modes

| Mode          | Channels per Pixel | What it stores                 | Common Use Case                                   |
| ------------- | ------------------ | ------------------------------ | ------------------------------------------------- |
| **Grayscale** | 1                  | Lightness/Brightness           | Black-and-white photos, scans of documents        |
| **RGB**       | 3                  | Red, Green, Blue               | Standard digital photos, web images               |
| **RGBA**      | 3 + Alpha          | Red, Green, Blue, Transparency | Logos, icons, images with transparent backgrounds |
