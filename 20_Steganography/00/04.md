To read file metadata (such as file size, permissions, timestamps, owner, and extended attributes) on Ubuntu, you can use
several built-in command-line tools.

---

### 1. General File Information: `stat`

The `stat` command is the most direct tool for viewing detailed file metadata, including the file type, size, blocks, I/O
block size, permissions, UID, GID, and access/modify/change timestamps.

- **Command:**

```bash
stat filename.txt

```

- **What it shows:** Everything from basic permissions to inode numbers and exact timestamps.

---

### 2. Viewing File Properties and Timestamps: `ls`

For a quick overview of basic metadata, the `ls` command with specific flags is commonly used.

- **Long format (permissions, owner, size, modification date):**

```bash
ls -l filename.txt

```

- **Show inode number (metadata index):**

```bash
ls -i filename.txt

```

- **Show access time instead of modification time:**

```bash
ls -lu filename.txt

```

---

### 3. Reading Extended File Attributes: `getfattr`

If your files use extended attributes (such as security labels, MIME types, or custom metadata stored by applications), you
can use `attr`. First, ensure it's installed (`sudo apt install attr`), then run:

- **Command:**

```bash
getfattr -d filename.txt

```

- **What it shows:** Any user-defined or system-defined extended attributes attached to the file.

---

### 4. Specialized Metadata (Images, Audio, Documents)

If you want to read embedded metadata inside specific file types (like EXIF data in photos, ID3 tags in MP3s, or author
details in PDFs):

- **For Images (EXIF data):** Use `exiftool` or `identify` (from ImageMagick).

```bash
sudo apt install libimage-exiftool-perl
exiftool image.jpg

```

- **For Audio Files (MP3/FLAC):** Use `metaflac` or `ffprobe`.

```bash
ffprobe audio.mp3

```

- **For PDFs and Documents:** Use `pdfinfo`.

```bash
sudo apt install poppler-utils
pdfinfo document.pdf

```
