To implement image steganography in Node.js and TypeScript, the most reliable approach is LSB (Least Significant Bit)
Steganography. By changing the very last bit of a pixel's color value (e.g., changing a Red value of 255 to 254), you alter
the image in a way that is completely invisible to the human eye. [1, 2, 3] To handle PNG images at the raw pixel level in
Node.js without external heavy C++ dependencies, we will use the popular [pngjs](https://www.npmjs.com/package/pngjs)
library.

## 📜 Complete Steganography Implementation

This complete TypeScript solution includes an Encoder (to hide any file or string inside a PNG) and a Decoder (to extract it
back). [4] To solve the "Where does the data end?" problem, this script prepends a 32-bit integer containing the exact length
of the hidden file payload before embedding the data bits. Create a file named stego.ts:

import \* as fs from 'fs';import { PNG } from 'pngjs'; /\*\*

- Encodes a secret file/string into a carrier PNG image.
- @param carrierPath Path to the original PNG image
- @param secretPath Path to the file you want to hide
- @param outputPath Path where the output PNG will be saved \*/export async function encode(carrierPath: string, secretPath:
  string, outputPath: string): Promise<void> { // 1. Read files into raw buffers const carrierBuffer =
  fs.readFileSync(carrierPath); const secretBuffer = fs.readFileSync(secretPath);

const png = PNG.sync.read(carrierBuffer);

// 2. Prepare the payload (4 bytes for file length prefix + actual secret data) const lengthBuffer = Buffer.alloc(4);
lengthBuffer.writeUInt32BE(secretBuffer.length, 0); const finalPayload = Buffer.concat([lengthBuffer, secretBuffer]);

const totalBitsNeeded = finalPayload.length \* 8; const maxBitsAvailable = png.data.length; // Each color channel (R, G, B,
A) holds 1 bit

if (totalBitsNeeded > maxBitsAvailable) { throw new
Error(`Secret file is too large! Needs ${totalBitsNeeded} bits, but image only has ${maxBitsAvailable} bits capacity.`); }

// 3. Bit Stream Generator function\* getBits(buffer: Buffer): Generator<number, void, unknown> { for (const byte of buffer)
{ for (let i = 7; i >= 0; i--) { yield (byte >> i) & 1; } } }

const bitIterator = getBits(finalPayload);

// 4. Inject bits into the Least Significant Bit (LSB) of each pixel channel for (let i = 0; i < png.data.length; i++) {
const nextBit = bitIterator.next(); if (nextBit.done) break; // Finished hiding all payload data

    const bit = nextBit.value;

    // Clear the LSB (mask with 11111110) and then bitwise OR with our secret bit
    png.data[i] = (png.data[i] & 0xFE) | bit;

}

// 5. Save the modified image safely as a lossless PNG const outputBuffer = PNG.sync.write(png); fs.writeFileSync(outputPath,
outputBuffer); console.log(`Success! Secret payload safely hidden inside: ${outputPath}`); } /\*\*

- Decodes and extracts hidden files from a steganographic PNG image.
- @param stegoImagePath Path to the image containing hidden data
- @param outputPath Path where the extracted secret file should be saved \*/export async function decode(stegoImagePath:
  string, outputPath: string): Promise<void> { const stegoBuffer = fs.readFileSync(stegoImagePath); const png =
  PNG.sync.read(stegoBuffer);

let bitCount = 0; let currentByte = 0;

// Helper array to hold extracted bytes sequentially const extractedBytes: number[] = []; let secretSizeInBytes: number |
null = null;

// Loop through pixel channels to reconstruct bytes for (let i = 0; i < png.data.length; i++) { const bit = png.data[i] & 1;
// Extract the LSB

    // Shift left and append the new bit
    currentByte = (currentByte << 1) | bit;
    bitCount++;

    if (bitCount === 8) {
      extractedBytes.push(currentByte);
      bitCount = 0;
      currentByte = 0;

      // Once we have extracted the first 4 bytes, parse the expected file size
      if (secretSizeInBytes === null && extractedBytes.length === 4) {
        const lengthBuffer = Buffer.from(extractedBytes);
        secretSizeInBytes = lengthBuffer.readUInt32BE(0);
      }

      // Check if we have extracted the full payload length
      if (secretSizeInBytes !== null && extractedBytes.length === 4 + secretSizeInBytes) {
        break;
      }
    }

}

if (secretSizeInBytes === null) { throw new Error("Failed to read a valid file size header from the image."); }

// Slice away the 4-byte header to get the pure original file payload const secretPayload =
Buffer.from(extractedBytes.slice(4)); fs.writeFileSync(outputPath, secretPayload);
console.log(`Success! Extracted secret file saved to: ${outputPath}`); }

## 🧠 Safety Rules for Image Steganography

1.  Always use Lossless formats: This technique relies entirely on exact pixel color mappings. Using JPEG formats will
    destroy your data because JPEG compression algorithms recalculate and smooth pixel colors to save space. Stick
    exclusively to .png or .bmp. [9, 10, 11]
2.  Handle Alpha Channels carefully: The pngjs library reads images as RGBA (Red, Green, Blue, Alpha). This script writes
    bits into the Alpha (transparency) channel too. If you are modifying highly transparent images, modifying the alpha
    channel might look slightly blocky; for standard images, it remains perfectly hidden. [12, 13]
