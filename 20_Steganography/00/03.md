**File metadata** is essentially "data about data." It is a set of standardized information that describes the
characteristics, structure, context, and management of a file, without looking at the actual content inside the file.

If a file is a book, the metadata is the information found on the cover and the copyright page (title, author, publication
date, and page count), rather than the text of the story itself.

---

### ## Common Types of File Metadata

Metadata is generally categorized into three main types:

- **Descriptive Metadata:** Information that helps identify and discover a file.
- _Examples:_ Title, author, subject, keywords, and description.

- **Structural Metadata:** Information about how a file is organized or put together.
- _Examples:_ How pages are ordered in a PDF, or how chapters are structured in an e-book.

- **Administrative Metadata:** Technical information that helps manage the file over time.
- _Examples:_ File type (format), file size, creation date, modification date, and permissions (who can read or edit it).

---

### ## Examples of Metadata by File Type

Different files store different types of metadata depending on their format and purpose:

| File Type                | Typical Metadata Stored                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Photos (JPEG/PNG)**    | Date and time taken, camera model, shutter speed, ISO, GPS location (EXIF data), and image dimensions. |
| **Documents (Word/PDF)** | Author name, revision number, word count, creation date, and editing history.                          |
| **Audio (MP3/WAV)**      | Song title, artist name, album, track number, genre, and length.                                       |
| **System Files**         | File permissions, owner ID, checksums, and storage location path.                                      |

---

### ## Why File Metadata is Important

- **Organization and Search:** Operating systems and search tools use metadata to let you sort files by date, filter by file
  type, or search for documents written by a specific author.
- **Digital Forensics and Privacy:** Photos taken on a smartphone often contain hidden GPS and device metadata. Removing
  metadata (or "scrubbing" it) before sharing files online is a common privacy practice.
- **Data Management:** Libraries, archives, and businesses rely on metadata to catalog massive databases, ensuring files
  remain accessible and properly classified over many years.
