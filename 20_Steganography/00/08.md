### Best Image Formats for Steganography

When choosing an image format for steganography, the primary consideration is **compression**. You generally want to avoid
formats that use lossy compression because the compression algorithm alters pixel data, which will likely destroy your hidden
secret message.

- **Lossless Formats (Recommended):**
- **PNG (Portable Network Graphics):** The absolute gold standard for image steganography. PNG uses lossless compression,
  meaning every single pixel's color value remains exact when saved and transmitted. This ensures that LSB (Least Significant
  Bit) manipulation remains intact.
- **BMP (Bitmap):** An uncompressed format. Because there is no compression at all, data can be embedded directly into the
  pixel bytes without any alteration. However, BMP files are very large, which makes them conspicuous when transferred over
  the internet.
- **TIFF (Tagged Image File Format):** Often used in professional photography because it supports lossless storage. Like BMP,
  it preserves exact pixel data, but file sizes are massive.

- **Lossy Formats (To Avoid):**
- **JPEG / JPG:** **Not recommended.** JPEG uses a lossy compression algorithm that discards color and detail data the human
  eye cannot easily perceive to shrink file sizes. Modifying a JPEG file or saving it will corrupt or completely erase hidden
  data. _(Note: Specialized steganography tools do exist for JPEGs, but they hide data in the Discrete Cosine Transform (DCT)
  coefficients rather than raw pixels, making it much more complex)._

### Best Audio Format for Steganography

Just like images, audio steganography requires formats that do not compromise data integrity through aggressive compression.

- **Lossless Formats (Recommended):**
- **WAV (Waveform Audio File Format):** The most popular and reliable format for audio steganography. WAV files store
  uncompressed (or losslessly compressed) audio samples. You can manipulate the least significant bits of the audio samples
  to hide data without altering the audible sound.
- **FLAC (Free Lossless Audio Codec):** Compresses audio to a smaller file size without losing a single bit of quality. While
  entirely viable, WAV is more commonly supported out-of-the-box by basic steganography scripts and tools.

- **Lossy Formats (To Avoid):**
- **MP3, AAC, OGG:** **Not recommended.** These formats use psychoacoustic modeling to throw away audio frequencies humans
  cannot hear. Just like JPEG compression, this discards hidden data payloads embedded in the audio stream.
