**PCM (Pulse-Code Modulation)** is a way of representing an analog sound signal as a sequence of **digital numbers**.

In simple terms:

> **PCM = samples + a number for each sample.**

### Example

Imagine a microphone produces this analog waveform:

```text
       /\          /\
      /  \        /  \
-----/----\------/----\-----
    /      \    /
```

An ADC (analog-to-digital converter) measures it at regular intervals:

```text
Time →    1    2    3    4    5    6    7

          ●    ●    ●    ●    ●    ●    ●
Value →  0   500  900  400 -400 -900 -300
```

Those numbers are **PCM samples**.

So PCM audio might conceptually look like:

```text
0, 500, 900, 400, -400, -900, -300, ...
```

---

### PCM has three important properties

**1. Sample rate — how often we measure**

For example:

**44,100 Hz**

means:

> 44,100 samples are taken every second.

Common rates:

- 44.1 kHz — CDs and lots of music
- 48 kHz — video/professional audio
- 96 kHz — higher-resolution recording

**2. Bit depth — how precisely each measurement is represented**

For example, **16-bit PCM** gives:

**65,536 possible levels**

approximately:

```text
-32768 ───────── 0 ───────── +32767
```

24-bit PCM gives vastly more possible levels.

**3. Number of channels**

For example:

```text
Mono:    1 channel
Stereo:  2 channels
5.1:     6 channels
```

Stereo PCM therefore contains two sequences of samples:

```text
Left:   L0 L1 L2 L3 L4 L5 ...
Right:  R0 R1 R2 R3 R4 R5 ...
```

---

### PCM is not the same thing as WAV

This distinction is important.

**PCM** is the actual digital audio representation.

**WAV** is a **file/container format** that can store PCM audio.

Think of it like:

```text
PCM = the audio data

WAV = a file that can contain that data
```

A WAV file might contain:

```text
WAV
├── Header
└── PCM data
    ├── sample
    ├── sample
    ├── sample
    └── ...
```

And **MP3 is different**: MP3 compresses the audio rather than simply storing the PCM samples directly.

```text
Microphone
    ↓
Analog signal
    ↓
ADC
    ↓
PCM samples
    ├──────────────→ WAV (can store PCM directly)
    │
    └→ MP3 encoder → MP3 (compressed)
```

So when you play an MP3, the MP3 decoder ultimately produces **PCM samples**, which are then sent to the DAC to become an
electrical waveform and finally sound from the speaker.
