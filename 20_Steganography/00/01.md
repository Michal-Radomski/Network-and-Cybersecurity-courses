**Steganography** is the practice of concealing a secret message, file, or image within another, ordinary, non-secret file
(known as a "carrier" or "cover" text/medium).

Unlike cryptography—which scrambles a message so people can read it only if they have a decryption key—steganography hides
the very _existence_ of the message. To an outside observer, it looks like a normal picture, audio file, or text document,
with no visible sign that data is hidden inside.

---

### How It Works

Steganography typically relies on altering the least important details of a carrier file so that the human eye or ear cannot
detect the change.

- **Digital Images:** The most common method involves tweaking the **Least Significant Bit (LSB)** of an image's pixel color
  values. Changing the last bit of a pixel's color channel changes the color by such a microscopic amount that it is
  completely invisible to the naked eye, but computers can extract those bits to read the hidden data.
- **Audio and Video:** Similar to images, data can be hidden in unused data frequencies or slightly modified frames.
- **Text:** Hidden messages can be embedded using subtle changes, such as extra white spaces between words, specific
  formatting, or acrostics (where the first letter of each sentence spells out a secret word).

---

### Real-World Example

Imagine you want to send a secret password. Instead of sending a text file called `password.txt`, you hide that text inside a
high-resolution vacation photo (`sunset.png`).

1. You use a steganography tool to embed the text file into the pixels of `sunset.png`.
2. You email or share the normal-looking vacation photo publicly.
3. The recipient downloads the photo, opens it with the same tool, and extracts the hidden text file. Anyone else looking at
   the photo just sees a sunset.

---

### Steganography vs. Cryptography

| Feature        | Steganography                                                                   | Cryptography                                                                    |
| -------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Main Goal**  | Hides the **existence** of a message.                                           | Hides the **content** of a message.                                             |
| **End Result** | Looks like ordinary, harmless data.                                             | Looks like unreadable, scrambled code/gibberish.                                |
| **Drawback**   | If discovered, the hidden data is usually unprotected (unless encrypted first). | Anyone can see that a secret message is being sent, even if they can't read it. |

> **Pro Tip:** In modern cybersecurity, these two techniques are often combined. A message is first encrypted using
> cryptography (so it's scrambled) and then hidden inside an image using steganography for double protection.
