Implementing steganography in Node.js typically involves modifying the **Least Significant Bit (LSB)** of image pixels to
hide data inside a cover image.

The easiest and most reliable way to achieve this in Node.js is by using community packages designed for this purpose, such
as `@mrdesjardins/steganography`, which handles the pixel manipulation and file reading/writing under the hood.

---

### Step 1: Install the Package

Open your terminal, initialize a Node.js project (if you haven't already), and install the steganography package:

```bash
npm init -y
npm install @mrdesjardins/steganography

```

---

### Step 2: Hide a Secret Message (Encoding)

To hide a message inside an image, use the `addMessageToImage` function. You can optionally secure your message with a
password using AES encryption.

Create a file named `encode.js`:

```javascript
const { addMessageToImage } = require("@mrdesjardins/steganography");

async function hideSecret() {
  try {
    const secretMessage = "This is a top-secret message hidden inside an image!";
    const inputImagePath = "./input.png"; // Path to your source image
    const outputImagePath = "./output.png"; // Path where the modified image will be saved

    console.log("Encoding message...");

    // Optional: Pass a password object for encryption
    await addMessageToImage(secretMessage, inputImagePath, outputImagePath, {
      password: "mySuperSecurePassword",
    });

    console.log(`Success! Secret hidden in ${outputImagePath}`);
  } catch (error) {
    console.error("Error encoding message:", error);
  }
}

hideSecret();
```

---

### Step 3: Extract the Secret Message (Decoding)

To retrieve the hidden message from the modified image, use the `getMessageFromImage` function. Make sure to supply the same
password if encryption was used during encoding.

Create a file named `decode.js`:

```javascript
const { getMessageFromImage } = require("@mrdesjardins/steganography");

async function revealSecret() {
  try {
    const outputImagePath = "./output.png"; // Path to the steganographic image

    console.log("Extracting message...");

    // Pass the same password if the message was encrypted
    const message = await getMessageFromImage(outputImagePath, {
      password: "mySuperSecurePassword",
    });

    console.log("Hidden Message Found:", message);
  } catch (error) {
    console.error("Error decoding message:", error);
  }
}

revealSecret();
```

### How LSB Steganography Works Behind the Scenes

Most software libraries accomplish this by adjusting the color channels (Red, Green, Blue, or Alpha) of an image:

- Every pixel has color values ranging from $0$ to $255$ (represented by 8 bits in binary).
- Changing the **Least Significant Bit** (the rightmost bit, e.g., changing a color value from `11011011` to `11011010`)
  changes the color shade by such an infinitesimally small amount that the human eye cannot detect the difference.
- The library sequentially writes the binary data of your text message into these tiny bit-level modifications across the
  image pixels.
