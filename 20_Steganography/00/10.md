The term **Least Significant Bit (LSB)** in the context of digital images refers to the bit in a binary number that carries
the least numerical weight—specifically, the rightmost bit.

When applied to images, LSB manipulation is the core technique behind **image steganography**, which is the practice of
concealing secret data (like text or another image) inside an ordinary, carrier image so that the changes remain invisible to
the human eye.

---

### How Pixel Colors Work in Binary

In a standard digital color image (using RGB format), every pixel is made up of three color channels: **Red**, **Green**, and
**Blue**. Each channel is represented by a single byte (8 bits), giving values from `0` to `255`.

For example, a pixel with a red value of `200` looks like this in binary:

- `11001000`
- **Most Significant Bit (MSB):** The leftmost bit (`1`), which holds a value of 128. Changing this bit drastically alters
  the color value (turning it into 72 or vice versa).
- **Least Significant Bit (LSB):** The rightmost bit (`0`), which holds a value of 1. Changing this bit only changes the
  color value by `1` (turning 200 into 201).

---

### How LSB Steganography Works

Because changing an LSB only alters a color value by a tiny fraction (e.g., shifting a shade of blue by just 1 level out of
256), the human eye cannot perceive any visual difference in the image.

1. **Convert Data to Binary:** A secret message is converted into a string of binary bits (`0`s and `1`s).
2. **Iterate Through Pixels:** The program loops through the pixels and color channels of the carrier image.
3. **Replace the LSB:** The least significant bit of a color channel is replaced with a bit from the secret message.
4. **Save Losslessly:** The modified image is saved using a lossless format like **PNG** (lossy formats like JPEG discard or
   alter data during compression, which would destroy the hidden message).

---

### Example Concept in Python

Building on your previous code where you modified individual pixels using `image.getpixel()` and `new_image.putpixel()`, an
LSB approach replaces just the final bit of a pixel channel using bitwise operations:

```python
from PIL import Image

# Opening an image
image = Image.open("example.png").convert("RGB")
width, height = image.size

# Example: Hiding a bit (let's say '1') into the red channel of the top-left pixel
r, g, b = image.getpixel((0, 0))

# Clear the LSB using a bitwise AND, then set it using bitwise OR
# r & 254 clears the last bit (makes it 0)
# | 1 sets the last bit to 1
new_r = (r & 254) | 1

# The visual difference between r and new_r is undetectable by the human eye
print(f"Original Red: {r}, Modified Red: {new_r}")

```

### Common Use Cases

- **Digital Watermarking:** Embedding copyright data or signatures into media to prove ownership.
- **Data Hiding / Steganography:** Securely transmitting notes or metadata inside seemingly normal photographs.
