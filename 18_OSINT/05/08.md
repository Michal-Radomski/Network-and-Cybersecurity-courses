Open Source Intelligence (OSINT) tools vary depending on whether you need a GUI-based desktop app, a command-line framework,
or web services.

Most Python-based CLI tools run natively on both **Windows** and **Linux**, provided Python is installed.

---

### **1. Graphical / Desktop Tools (Cross-Platform)**

- **Maltego** _(Windows, Linux, macOS)_
- **Best For:** Visualizing relationships and mapping digital footprints.
- **Overview:** A premier link-analysis platform that creates visual graphs connecting IP addresses, domains, email
  addresses, social media profiles, and company data.

- **SpiderFoot** _(Windows, Linux, macOS)_
- **Best For:** Automated threat intelligence and footprinting.
- **Overview:** Offers both a command-line and a web GUI interface. It automatically queries over 100 public data sources
  (DNS, WHOIS, Web servers, data breaches) to build target profiles.

- **Lampyre** _(Windows)_
- **Best For:** PC-native data analysis and investigation.
- **Overview:** A desktop application designed for Windows that collects, analyzes, and visualizes data from various sources
  (social networks, messaging apps, public databases).

---

### **2. Command-Line & Python Tools (Linux & Windows via CLI/WSL)**

- **Sherlock**
- **Best For:** Username hunting across social media.
- **Overview:** A lightweight Python tool that searches for a specific username across over 400+ social media platforms and
  websites simultaneously.

- **Maigret**
- **Best For:** Advanced username footprinting.
- **Overview:** Built as an evolution of Sherlock, Maigret checks over 2,000+ sites, parses user profile pages, and extracts
  extra metadata (avatars, bio text, locations).

- **theHarvester**
- **Best For:** Enterprise domain reconnaissance.
- **Overview:** A staple tool (pre-installed on Kali Linux) used to gather emails, subdomains, hosts, employee names, and
  open ports using search engines and public databases.

- **Recon-ng**
- **Best For:** Full-featured OSINT reconnaissance.
- **Overview:** A modular framework written in Python with an interface similar to Metasploit. It allows you to run targeted
  modules for domain, IP, contact, and repository discovery.

- **Holehe**
- **Best For:** Email address reverse lookups.
- **Overview:** Checks if a target email address is attached to accounts on over 120+ popular sites (like Twitter, Instagram,
  Imgur) using password-reset endpoints without alerting the target.

---

### **3. Web-Based Search & Discovery Tools (Platform Agnostic)**

While not strictly downloadable software, these web platforms are foundational to any Windows/Linux OSINT workflow:

- **Shodan** – A search engine for internet-connected devices (servers, IoT, webcams, industrial systems).
- **Censys** – Similar to Shodan, focusing on domain and IP attack surface discovery.
- **OSINT Framework (`osintframe.work`)** – An interactive directory index that organizes hundreds of OSINT resources by
  category.
- **Have I Been Pwned (HIBP)** – Checks if email addresses or phone numbers have been exposed in historical data breaches.

---

### **Recommendations for Deployment**

- **On Windows:** Python-based CLI tools (like Sherlock or Holehe) can be run easily via **PowerShell**, **Command Prompt**,
  or **Windows Subsystem for Linux (WSL)**.
- **On Linux:** Specialized distributions like **Kali Linux** or **Parrot Security OS** come with many of these tools (like
  `theHarvester` and `Recon-ng`) pre-installed.
