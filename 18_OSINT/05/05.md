## Overview of Bellingcat's OpenStreetMap Search Tool

The **Bellingcat OpenStreetMap Search Tool** is a web-based utility designed by the investigative journalism organization
Bellingcat to help open-source researchers, journalists, and OSINT (Open Source Intelligence) analysts geolocate images and
videos.

Instead of requiring users to learn complex query languages, this tool simplifies the process of searching crowdsourced map
data from OpenStreetMap (OSM).

---

### Key Features

- **Proximity Searches:** Allows users to search for multiple geographic features that need to be within a specific distance
  of each other. For example, a researcher can look for an area that contains a school, a supermarket, and a road with
  sidewalks all packed within a certain radius.
- **Simplified Interface:** Serves as a more user-friendly, streamlined alternative to traditional tools like _Overpass
  Turbo_, removing the need to manually write complex Overpass QL code.
- **Geolocation Leads:** Helps narrow down vast geographical regions into specific, manageable areas of interest when trying
  to pinpoint where a photo or video was taken based on background landmarks or structures.

---

### Common Use Cases

- **Investigative Journalism:** Tracing the locations of events, tracking infrastructure developments, or verifying
  user-generated media from conflict zones or disaster areas.
- **Urban Planning & Environment:** Monitoring changes in land use, green spaces, or transportation networks over time.

---

### How to Access It

- **Hosted Tool:** You can find the live tool hosted by Bellingcat at
  [osm-search.bellingcat.com](https://osm-search.bellingcat.com/).
- **Source Code:** The project is open-source and available on GitHub via the `bellingcat/osm-search` repository for those
  interested in self-hosting or reviewing how it works.
