To view or extract EXIF data from an image on Ubuntu, you can use several simple and powerful command-line tools or a
graphical user interface (GUI) application.

Here are the best methods available:

---

### Method 1: Using `exiftool` (Most Comprehensive)

`exiftool` is the gold standard for reading and writing image metadata. It supports a vast array of file types and displays
every piece of hidden data available.

1. **Install ExifTool:**

```bash
sudo apt update
sudo apt install libimage-exiftool-perl

```

2. **Run the command on your image:**

```bash
exiftool image.jpg

```

_Tip: If you want to filter for specific information like the camera model or date taken, you can pipe the output into
`grep`:_

```bash
exiftool image.jpg | grep -i "date"

```

---

### Method 2: Using `exif` (Lightweight Command-Line Tool)

If you just want a quick, neatly formatted table of standard EXIF tags (like camera settings, exposure, and date) without
overwhelming detail, the `exif` utility is ideal.

1. **Install Exif:**

```bash
sudo apt update
sudo apt install exif

```

2. **Run the command on your image:**

```bash
exif image.jpg

```

---

### Method 3: Using `identify` (ImageMagick)

If you already have ImageMagick installed (which is common on Ubuntu systems), its `identify` command can pull basic metadata
instantly.

1. **Install ImageMagick (if not already installed):**

```bash
sudo apt update
sudo apt install imagemagick

```

2. **Run the command with verbose output:**

```bash
identify -verbose image.jpg

```

---

### Method 4: Using a Graphical Interface (GUI)

If you prefer not to use the terminal, you can easily view EXIF data using Ubuntu's default image viewer or a dedicated photo
manager.

- **Shotwell or gThumb:** Open your image in **Shotwell** or **gThumb** (which can be installed via the Ubuntu Software
  Center or `sudo apt install gthumb`), right-click the image, and select **Properties** or **Metadata** to see camera
  details, shutter speed, and location data.
- **Exif Viewer (Browser Extension / App):** Alternatively, you can open the image in a web browser with an EXIF viewer
  extension installed.
