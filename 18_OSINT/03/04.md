### Essential OSINT Tools

Open Source Intelligence (OSINT) relies on gathering data from publicly available sources. Because investigations span
various domains—such as username tracking, domain reconnaissance, and social media analysis—investigators rely on a core set
of industry-standard tools.

---

### 1. Username & Identity Reconnaissance

- **Sherlock:** A command-line tool that searches social media platforms across hundreds of websites for a specific username,
  helping to identify an individual's digital footprint.
- **Maigret:** Similar to Sherlock, but extracts more detailed information, checks a wider range of sites, and maps out
  connections between found accounts.

### 2. Domain & Infrastructure Intelligence

- **TheHarvester:** Designed for early-stage penetration testing and OSINT gathering, this tool collects emails, subdomains,
  hosts, employee names, and open ports from public sources like search engines and PGP key servers.
- **Shodan:** Often called the search engine for internet-connected devices, Shodan allows investigators to find servers,
  routers, webcams, and other IoT devices exposed to the internet.
- **SpiderFoot:** An automation tool that integrates with dozens of OSINT data sources to gather intelligence on IP
  addresses, domains, e-mails, and usernames automatically.

### 3. Email & Breach Intelligence

- **Holehe:** A tool that checks if an email address is attached to accounts on various sites (like Twitter, Instagram, or
  Amazon) by leveraging password reset endpoints.
- **Have I Been Pwned (HIBP):** A crucial database and API used to check if email addresses or phone numbers have been
  compromised in data breaches.

### 4. Social Media & Content Analysis

- **Twint (or alternative Twitter/X scrapers):** Tools used to scrape tweets, user profiles, and followers without using the
  official Twitter API (though subject to platform changes and rate limits).
- **Sherloq / ExifTool:** Command-line utilities used for forensic image analysis. They extract hidden metadata (EXIF data)
  from photos, including timestamps, camera models, and sometimes GPS coordinates.

### 5. Geolocation & Mapping

- **Google Earth Pro / Google Maps:** Essential for verifying physical locations, comparing historical satellite imagery, and
  analyzing terrain.
- **SunCalc:** A tool used to calculate sun angles and shadows at specific times and dates, which helps verify the time a
  photo or video was taken.
