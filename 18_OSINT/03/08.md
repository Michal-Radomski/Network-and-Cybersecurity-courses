To install **Sherlock** on Ubuntu, follow these steps to set it up properly using Python and `pipx`:

### Step 1: Update Your Package List

Open your terminal and ensure your package manager is up to date:

```bash
sudo apt update

```

### Step 2: Install Python and Pipx

Sherlock requires Python. Installing it along with `pipx` (which keeps Python command-line tools isolated and prevents system
errors) is the cleanest method:

```bash
sudo apt install python3 python3-pip pipx

```

Make sure `pipx` is configured to add applications to your system's path:

```bash
pipx ensurepath

```

_(Note: If you just ran `pipx ensurepath`, close and reopen your terminal window, or run `source ~/.bashrc`, to ensure the
path updates take effect)._

### Step 3: Install Sherlock

Once `pipx` is ready, install Sherlock directly from the package index:

```bash
pipx install sherlock-project

```

### Step 4: Verify the Installation

Check that Sherlock installed successfully by running:

```bash
sherlock --version

```

You can now use Sherlock by running commands like:

```bash
sherlock username_here

```
