### Overview of Instaloader and Toutatis

**Instaloader** and **Toutatis** are both open-source Python-based tools commonly used in Open Source Intelligence (OSINT)
and digital research for interacting with and gathering data from Instagram.

---

### 1. Instaloader

**Instaloader** is a command-line tool and Python library designed to download and archive publicly available content (and
permitted private content when authenticated) from Instagram.

- **Primary Function:** It allows users to save posts, stories, reels, highlights, and profile pictures along with their
  associated metadata (captions, timestamps, geotags, and comments).
- **Key Use Cases:** \* **Digital Archiving:** Preserving content and media locally for research or historical reference
  before posts are deleted or accounts go private.
- **Content Analysis:** Analyzing media files and text data programmatically using Python scripts to spot trends, check
  timelines, or review engagement.

- **How It Works:** It can run via simple terminal commands or be integrated into custom automation workflows, respecting
  rate limits and handling session persistence.

---

### 2. Toutatis

**Toutatis** is an OSINT tool specifically built to extract specific profile details from Instagram accounts.

- **Primary Function:** It targets a specific Instagram username to retrieve associated public data points, such as full
  names, biography details, follower counts, and obfuscated contact information (like masked phone numbers or email addresses
  linked to password recovery features).
- **Key Use Cases:**
- **Profile Reconnaissance:** Gathering background details on an account during authorized digital investigations.
- **Passive Information Gathering:** Operating via Instagram's application logic without triggering direct alerts or
  notifications to the target user.

- **How It Works:** It uses session tokens or queries to interact with Instagram's API endpoints, parsing the returned JSON
  data to present structured account information back to the investigator.
