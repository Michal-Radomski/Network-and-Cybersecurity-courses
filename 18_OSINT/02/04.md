**BitTorrent** is a peer-to-peer (P2P) file-sharing protocol. Instead of downloading a file from a single server, you
download small pieces of it from multiple people (called _peers_) who already have those pieces. At the same time, your
computer uploads the pieces you've already downloaded to other peers.

This approach can make downloads faster and reduces the load on any single server.

### Key concepts

- **Torrent file (.torrent):** A small metadata file that tells your BitTorrent client what to download and how to find
  peers.
- **Magnet link:** A link that contains the information needed to start downloading without first downloading a `.torrent`
  file.
- **Peers:** People sharing the file.
- **Seeders:** Peers with the complete file who are uploading it.
- **Leechers:** Peers still downloading the file (they may also upload parts they've already received).

The more seeders there are, the better download speeds tend to be.

## Is BitTorrent legal?

The BitTorrent protocol itself is completely legal. Many organizations use it to distribute large files efficiently,
including:

- Linux distributions (such as Ubuntu ISOs)
- Open-source software
- Public-domain media
- Large research datasets

However, downloading or sharing copyrighted material without permission may be illegal depending on your jurisdiction.

## Installing a BitTorrent client on Ubuntu

Ubuntu has several good BitTorrent clients.

### Option 1: Transmission (recommended)

Transmission is lightweight and often comes preinstalled on Ubuntu.

If it isn't installed:

```bash
sudo apt update
sudo apt install transmission-gtk
```

Launch it from the Applications menu or:

```bash
transmission-gtk
```

### Option 2: qBittorrent

A more feature-rich client.

```bash
sudo apt update
sudo apt install qbittorrent
```

Start it with:

```bash
qbittorrent
```

## Downloading a file

### Using a magnet link

1. Open your browser.
2. Click a magnet link.
3. Choose your BitTorrent client.
4. Select the download location.
5. Click **OK** or **Download**.

### Using a .torrent file

1. Download the `.torrent` file.
2. Open your BitTorrent client.
3. Select **File → Open Torrent**.
4. Choose the `.torrent` file.
5. Pick the destination folder.
6. Start the download.

## Example: Download Ubuntu via BitTorrent

Ubuntu publishes official torrent downloads for its installation images.

1. Go to Ubuntu's download page.
2. Download the torrent or click the magnet link.
3. Open it with your BitTorrent client.
4. Wait for the download to complete.

After downloading, it's helpful to leave the client running for a while so you can upload the file to others (this is called
**seeding**).

## Useful settings

- Choose a download folder.
- Set upload/download speed limits if needed.
- Configure maximum active downloads.
- Enable encryption if your client supports it.
- Optionally enable port forwarding on your router for better connectivity.

## Staying safe

- Download only from trusted sources.
- Scan downloaded files with antivirus software if appropriate.
- Verify checksums (SHA-256, etc.) when they're provided, especially for operating system images.
- Keep your BitTorrent client up to date.

## Command-line option

If you prefer the terminal, you can install Transmission's CLI:

```bash
sudo apt install transmission-cli
```

Then download using:

```bash
transmission-cli "magnet:?xt=urn:btih:..."
```

or

```bash
transmission-cli example.torrent
```

This is useful for servers or headless Ubuntu systems.

For most desktop Ubuntu users, **Transmission** is the simplest choice, while **qBittorrent** is a good option if you want
more advanced features such as search plugins, RSS downloads, and detailed bandwidth controls.
