**ripgrep** (`rg`) is a fast command-line search tool for finding text inside files and directories. It's often considered a
modern replacement for `grep` when searching through source code or large projects.

It is written in Rust and is optimized for speed.

### Why use ripgrep instead of grep?

Compared to `grep`, ripgrep:

- ⚡ Searches much faster in most cases.
- 📁 Recursively searches directories by default (no `-r` needed).
- 🙈 Automatically ignores files listed in `.gitignore` and hidden files (unless you tell it not to).
- 🎨 Produces colorized output by default.
- 🔤 Supports regular expressions.

For example, suppose you have this project:

```text
project/
├── main.py
├── utils.py
├── README.md
└── .git/
```

To find every occurrence of `database`:

```bash
rg database
```

Output:

```text
main.py
15:database.connect()

utils.py
8:database.close()
```

## Installing on Ubuntu

```bash
sudo apt update
sudo apt install ripgrep
```

Verify the installation:

```bash
rg --version
```

## Common examples

### Search for a word

```bash
rg error
```

### Search in a specific directory

```bash
rg TODO ~/projects
```

### Search only Python files

```bash
rg "import numpy" -g "*.py"
```

### Ignore case

```bash
rg -i ubuntu
```

Matches:

- Ubuntu
- ubuntu
- UBUNTU

### Show line numbers

```bash
rg -n password
```

### Search hidden files too

```bash
rg --hidden secret
```

### Include ignored files

```bash
rg -uu TODO
```

## ripgrep vs grep

| Feature                      | grep     | ripgrep (`rg`) |
| ---------------------------- | -------- | -------------- |
| Recursive by default         | ❌       | ✅             |
| Uses `.gitignore`            | ❌       | ✅             |
| Very fast on large codebases | Good     | Excellent      |
| Color output                 | Optional | Default        |
| Great for source code        | Good     | Excellent      |

## When is it useful?

Developers commonly use ripgrep to:

- Find where a function or variable is used.
- Search for configuration values.
- Locate error messages in log files.
- Search through large codebases quickly.

For example, to find every occurrence of `main` in your current project:

```bash
rg "main"
```

Or to search your entire home directory for `ssh`:

```bash
rg ssh ~
```

In summary, if you frequently search through files on Ubuntu—especially source code—**ripgrep** is one of the most useful
command-line tools to have. It combines the familiar pattern-matching capabilities of `grep` with faster performance and
convenient defaults.
