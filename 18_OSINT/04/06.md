**Blackbird** is an open-source Open Source Intelligence (OSINT) reconnaissance tool developed by developer Lucas Antoniaci
(_p1ngul1n0_). It is designed to perform reverse account lookups by searching for specific usernames or email addresses
across hundreds of online platforms.

---

## Key Features

- **Platform Coverage:** Blackbird leverages integration with community-driven databases like the **WhatsMyName** project,
  allowing it to query over 600 to 700+ websites and social networks.
- **AI-Powered Behavioral Profiling:** Unlike traditional account enumeration tools, Blackbird includes an optional, free AI
  analysis feature. By examining the types of platforms where a target's username or email is discovered, the AI generates a
  behavioral and technical summary of the target's online footprint.
- **Metadata Extraction:** Beyond verifying account presence, it automatically pulls publicly available details from matched
  profiles (such as profile images, display names, and listed locations).
- **Flexible Interfaces:** It operates primarily as a Command Line Interface (CLI) tool for automation, but also includes a
  local web server mode for a browser-based GUI.
- **Export & Filtering Options:** Results—including AI summaries—can be exported directly into formatted PDF, CSV, JSON, or
  raw HTTP response formats. Users can also filter searches by category (e.g., social, coding, alternative media).

---

## Common Use Cases

- **Digital Investigations:** Used by cybersecurity professionals and OSINT analysts to map out a target's digital footprint.
- **Identity Verification:** Helps researchers verify whether an online identity or email is reused across multiple services.
- **Red Teaming & Profiling:** Assists security teams in assessing exposed public information or social engineering attack
  surfaces.

---

## Basic Command Line Examples

```bash
# Search by Username
python blackbird.py --username targetuser

# Search by Email Address
python blackbird.py --email targetuser@example.com

# Run a Search with AI Profiling Enabled
python blackbird.py --username targetuser --ai

# Export Findings to PDF Report
python blackbird.py --username targetuser --pdf

```
