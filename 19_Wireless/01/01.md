Wireless security and Wireless Local Area Network (WLAN) security focus on protecting networks that transfer data through
radio waves instead of physical cables. Because wireless signals broadcast in all directions and can easily pass through
walls, anyone within range can potentially intercept traffic or attempt to join the network.

Securing a WLAN involves protecting both the **data in transit** (encryption) and **controlling who gets access**
(authentication).

---

## 1. Key Encryption Protocols (Evolution)

Over the years, wireless security standards developed by the Wi-Fi Alliance have evolved to fix vulnerabilities in earlier
protocols.

- **WEP (Wired Equivalent Privacy):** The original 1999 security standard. It is severely flawed and easily cracked in
  minutes using modern tools. **Do not use.**
- **WPA (Wi-Fi Protected Access):** Introduced as a temporary fix for WEP. It added the **TKIP** (Temporal Key Integrity
  Protocol) encryption algorithm, but it is also obsolete today.
- **WPA2:** Released in 2004, WPA2 became the industry standard for a long time. It introduced strong **AES** (Advanced
  Encryption Standard) encryption via **CCMP**. While still widely used, it has known vulnerabilities (like the KRACK
  attack).
- **WPA3:** The current state-of-the-art standard introduced in 2018. It protects against brute-force password guessing using
  **SAE** (Simultaneous Authentication of Equals) and provides stronger encryption for enterprise networks.

---

## 2. Authentication Modes

WLAN security generally operates in one of two modes depending on the environment:

### Personal Mode (WPA2/WPA3-Personal)

- **How it works:** Uses a static password or passphrase known as a **Pre-Shared Key (PSK)**.
- **Best for:** Homes and small offices.
- **Limitation:** If one person shares the password, the whole network is compromised.

### Enterprise Mode (WPA2/WPA3-Enterprise)

- **How it works:** Requires each user to log in with individual credentials (username/password or digital certificates). It
  uses an external **RADIUS server** for central management (IEEE 802.1X standard).
- **Best for:** Businesses, universities, and large organizations.
- **Advantage:** Access can be revoked for a single employee without changing the password for everyone else.

## 3. Common Wireless Threats

Understanding wireless security requires knowing what attackers try to exploit:

| Threat                              | Description                                                                                                                                                               |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Eavesdropping / Packet Sniffing** | Intercepting unencrypted data passing through the air.                                                                                                                    |
| **Rogue Access Points**             | Unauthorized Wi-Fi routers connected to a corporate network by employees or attackers.                                                                                    |
| **Evil Twin Attack**                | A fake access point setup by an attacker using the exact same SSID (network name) as a legitimate network to trick users into connecting.                                 |
| **Man-in-the-Middle (MitM)**        | An attacker positioning themselves between a user and the router to view or alter data.                                                                                   |
| **Deauthentication Attacks**        | Sending fake disconnect packets to kick devices off a network, often forcing them to reconnect so an attacker can capture the handshake or redirect them to an Evil Twin. |

---

## 4. Best Practices for Securing a WLAN

1. **Use WPA3 or WPA2-AES:** Disable older legacy protocols like WEP, WPA, and TKIP.
2. **Use Strong Passwords:** Ensure PSKs are long, complex, and unpredictable.
3. **Disable WPS (Wi-Fi Protected Setup):** WPS allows easy connection via a PIN, but the PIN mechanism is easily
   brute-forced.
4. **Implement Network Segmentation:** Place guest users on a separate VLAN so they cannot see internal devices (like
   printers or servers).
5. **Use a VPN on Public Wi-Fi:** Always encrypt traffic when connected to open networks in cafes or airports.
6. **Keep Firmware Updated:** Patch routers and access points regularly to fix security vulnerabilities.
