## Segmentation of Wireless Local Area Networks (WLAN)

**WLAN segmentation** is the practice of dividing a single wireless network infrastructure into multiple, isolated virtual
zones or sub-networks. Instead of placing all devices—such as employee laptops, guest smartphones, and smart home
appliances—on the same flat network, segmentation enforces security boundaries so that traffic between zones is strictly
controlled.

---

## 1. Why WLAN Segmentation is Necessary

On a non-segmented (flat) wireless network, every connected device can potentially see and communicate with every other
device. This introduces major risks:

- **Lateral Movement:** If an attacker or a piece of malware compromises one low-security device (like a smart television or
  a guest's phone), they can freely scan and attack other sensitive devices (like corporate databases or personal file
  servers) on the same network.
- **Lack of Access Control:** Visitors or untrusted devices would have the same level of network visibility as trusted users
  or administrators.
- **Performance Bottlenecks:** Heavy, unmanaged traffic from resource-intensive devices can degrade overall wireless
  performance.

---

## 2. Common Categories of WLAN Segments

In both enterprise and advanced residential setups, a segmented WLAN is typically split into distinct operational groups:

| Segment                        | Intended Devices                                            | Security Purpose                                                                                                       |
| ------------------------------ | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Main / Corporate Network**   | Trusted employee laptops, workstations, and smartphones     | Requires strong authentication (e.g., WPA3-Enterprise or WPA3-Personal) and grants access to internal resources.       |
| **Guest Network**              | Visitors, clients, or temporary users                       | Provides **internet-only** access. Devices are completely isolated from one another and cannot see internal resources. |
| **IoT / Smart Device Network** | Smart TVs, security cameras, smart plugs, voice assistants  | Keeps inherently vulnerable or poorly patched smart devices quarantined away from sensitive user data.                 |
| **Admin / Management Network** | IT administrators, network switches, routers, and firewalls | Highly restricted zone used strictly for managing infrastructure equipment.                                            |

---

## 3. Core Technologies Used to Implement WLAN Segmentation

Network administrators use a combination of software and hardware definitions to achieve logical separation without needing
entirely separate physical infrastructure:

### A. Multiple SSIDs (Service Set Identifiers)

An Access Point (AP) can broadcast multiple Wi-Fi network names (SSIDs) simultaneously—for example, _"CompanySecure"_,
_"CompanyGuest"_, and _"CompanyIoT"_. Each SSID is bound to a unique security policy and encryption type.

### B. Virtual Local Area Networks (VLANs)

While users connect over the air to different SSIDs, underlying network switches and routers use **VLAN tags** (IEEE 802.1Q)
to logically separate the data packets. Even though traffic travels over the same physical Ethernet cables and access points,
packets are segregated into distinct broadcast domains.

### C. Inter-VLAN Routing and Firewall Rules

By default, traffic between different VLANs/segments is blocked. To allow controlled communication (e.g., allowing an
employee laptop to print to a network printer on a different segment, but blocking everything else), network engineers
configure **firewall access control lists (ACLs)** at the gateway router.

### D. Client Isolation (AP Isolation)

Often enabled on guest networks, this feature ensures that wireless clients connected to the same Access Point cannot talk
directly to each other peer-to-peer, neutralizing local wireless sniffing threats.
