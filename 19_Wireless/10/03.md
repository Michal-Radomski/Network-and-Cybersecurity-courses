Configuring a **Remote Access Point (RAP)** typically involves setting up both the central corporate network (the headend
controller/VPN gateway) and the physical access point device itself so that it can establish a secure tunnel over the
internet.

---

### Step 1: Configure the Central Headend (VPN Concentrator / Controller)

Before setting up the remote physical device, your corporate IT infrastructure must be prepared to accept incoming remote
connections.

- **Define IP Pools:** Create an internal IP address pool on your firewall, VPN concentrator, or mobility controller (such as
  an Aruba or Cisco gateway) specifically assigned to remote AP clients.
- **Set Up Authentication:** Configure authentication credentials (such as Pre-Shared Keys, certificates, or 802.1X/RADIUS)
  so the controller can securely verify the identity of the incoming access point.
- **Add to Whitelist:** Register the remote access point's MAC address or serial number into the controller's trusted
  whitelist/inventory database.
- **Firewall Rules:** Ensure your corporate public gateway allows incoming traffic on the required ports (such as UDP
  500/4500 for IPsec NAT Traversal) to reach the VPN concentrator.

---

### Step 2: Configure the SSID and Security Policies

Next, define what network profile the remote access point will broadcast.

- **Create Corporate SSIDs:** Configure the wireless network name, encryption type (e.g., WPA3-Enterprise or WPA2-PSK), and
  VLAN mappings.
- **Configure Traffic Forwarding (Split Tunneling):** \* Decide whether **all** traffic should go through the corporate
  tunnel (full tunneling) or if internet-bound traffic (like streaming or casual web browsing) should bypass the corporate
  network and go straight out via the local ISP (split tunneling) to save bandwidth.
- **Apply Access Control Lists (ACLs):** Restrict what network resources the remote users can access based on security
  policies.

---

### Step 3: Provision and Deploy the Remote Access Point

Most modern enterprise environments use **Zero-Touch Provisioning (ZTP)** to make deployment seamless for remote workers.

- **Initial Connection:** The physical access point is shipped to the remote location (like an employee's home). When plugged
  into power and a local internet router via an Ethernet cable, it obtains a local IP address via DHCP.
- **Cloud or Controller Discovery:** The AP contacts a cloud provisioning service (like Aruba Central or Cisco Meraki Cloud)
  or uses a pre-configured domain name (FQDN) to locate the corporate headquarters.
- **Secure Tunnel Establishment:** The AP automatically initiates an encrypted **IPsec VPN tunnel** back to the corporate
  controller using its validated credentials.
- **Configuration Download:** Once the tunnel is verified and active, the AP downloads its assigned wireless configuration
  and begins broadcasting the corporate Wi-Fi network locally.
