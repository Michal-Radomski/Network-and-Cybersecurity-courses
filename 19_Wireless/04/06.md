**EAP** stands for **Extensible Authentication Protocol**. It is not a single password-checking tool or login method; rather,
it is a **flexible framework** used in computer networking to support many different types of authentication.

Think of EAP as a **universal adapter** or a secure container. Instead of forcing a network to use only one type of login
(like a simple password), EAP provides a standard structure that allows devices to use passwords, digital certificates, smart
cards, or biometric data to prove who they are.

---

### Why is EAP "Extensible"?

The word "extensible" means it can be expanded or updated. When EAP was created, it was designed so that engineers could
invent new, more secure login methods in the future without having to rewrite the entire underlying network architecture.

---

### How EAP Fits Together with 802.1X

As discussed with 802.1X, network access control needs a way to transport identification data safely between a user's device
and a security server. EAP is the protocol that handles that exact job:

1. **The Supplicant** (your laptop or phone) wants to join a network.
2. **The Authenticator** (the Wi-Fi router or network switch) prompts for credentials.
3. **The EAP Framework** packages those requests and responses back and forth.
4. **The Authentication Server** (like a RADIUS server) runs the specific EAP method to verify everything.

---

### Popular EAP Methods (Types)

Depending on how strict security needs to be, networks can plug different "methods" into the EAP framework:

- **EAP-TLS (Transport Layer Security):** One of the most secure options. It requires **mutual authentication**, meaning the
  user's device checks the server's digital certificate, and the server checks the user's digital certificate. There are no
  static passwords to steal.
- **PEAP (Protected EAP):** Developed jointly by Cisco, Microsoft, and RSA. It creates an encrypted SSL/TLS "tunnel" first,
  and then safely passes a standard username and password inside that tunnel so eavesdroppers can't see it.
- **EAP-TTLS (Tunneled Transport Layer Security):** Similar to PEAP, it builds a secure tunnel to handle user credentials,
  offering great flexibility for integrating with older or legacy user databases.

---

### Where is EAP Used?

- **Enterprise Wi-Fi (WPA2/WPA3-Enterprise):** Used by universities, large corporations, and hospitals so users must log in
  with individual credentials instead of a single shared Wi-Fi password.
- **VPNs (Virtual Private Networks):** Used to securely authenticate remote workers before granting access to internal
  company resources.
- **Point-to-Point Connections:** Used in various broadband and telecom network setups to verify subscriber access.
