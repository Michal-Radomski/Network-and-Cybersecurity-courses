## AAA Framework in Network Security

The **AAA framework** is a foundational security architecture used to control access to computer networks, enforce security
policies, and track user activity. It stands for **Authentication**, **Authorization**, and **Accounting**, often referred to
as the "Triple A" of network administration.

---

### The Three Pillars of AAA

- **Authentication (Who are you?):** \* The process of verifying the identity of a user, device, or system trying to access a
  network.
- Common methods include usernames and passwords, multi-factor authentication (MFA), biometric scans, or digital
  certificates.
- _Example:_ Entering your corporate username and password when logging into the office Wi-Fi.

- **Authorization (What are you allowed to do?):** \* Once identity is verified, authorization determines what resources,
  data, or commands the user has permission to access.
- It relies on security policies, user roles, and access control lists (ACLs).
- _Example:_ A standard employee can access the internet and shared office files, but only network administrators are
  authorized to change router configurations.

- **Accounting (What did you do?):** \* The process of tracking and logging user activities and network resource consumption.
- It measures parameters such as session duration, data transferred, and timestamps for auditing, billing, and security
  analysis.
- _Example:_ An IT department tracks how much bandwidth a guest user consumed or reviews logs to see when a specific user
  logged into a secure server.

---

### How AAA Works Together

| Component          | Core Question        | Action Performed                                                                  |
| ------------------ | -------------------- | --------------------------------------------------------------------------------- |
| **Authentication** | Who are you?         | Validates credentials against a database (e.g., Active Directory, RADIUS server). |
| **Authorization**  | What can you access? | Grants or denies specific privileges based on the authenticated identity.         |
| **Accounting**     | What did you do?     | Records session details and resource usage for auditing and tracking.             |

---

> **Protocol Note:** AAA frameworks are typically implemented using centralized backend protocols such as **RADIUS** (Remote
> Authentication Dial-In User Service) or **TACACS+** (Terminal Access Controller Access-Control System Plus), allowing large
> organizations to manage network security across multiple devices and locations from a single platform.
