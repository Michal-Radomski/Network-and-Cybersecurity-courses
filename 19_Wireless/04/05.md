A **nonce** (short for **"number used once"**) is an arbitrary, random, or semi-random number generated specifically for use
in a single cryptographic communication, transaction, or session.

Once a nonce is used, it is discarded and never reused, serving as a critical building block for digital security,
authentication, and blockchain technology.

---

### Why Nonces Matter

- **Prevents Replay Attacks:** If an attacker intercepts a valid message or login command sent over a network, they might try
  to copy and resend it (a "replay attack") to impersonate the user. If the message includes a unique nonce that the server
  immediately invalidates after one use, the replayed message will be rejected.
- **Ensures Unique Encrypted Outputs:** In encryption algorithms (like AES-GCM), encrypting the exact same plaintext message
  with the same key will normally produce the exact same ciphertext. Introducing a unique nonce ensures that every single
  encryption operation yields a completely different output, hiding patterns from attackers.

---

### Common Use Cases

#### 1. Cryptography and Network Protocols (SSL/TLS)

During secure handshakes (like when your browser connects to a secure HTTPS website), both the client and the server exchange
random nonces. These nonces are mixed into the encryption keys to guarantee that the session keys are completely unique to
that specific connection, even if the same users connect every day.

#### 2. Blockchain and Proof of Work (e.g., Bitcoin)

In Proof-of-Work blockchains, a nonce is a variable number that miners append to block data.

- Miners continuously change the nonce and run the block header through a cryptographic hash function.
- Their goal is to find a nonce that generates a hash output meeting a specific network target (such as starting with a
  certain number of zeros).
- Because hashes are completely unpredictable, miners must perform this trial-and-error process billions of times until they
  hit a winning nonce.

#### 3. Transaction Sequencing (e.g., Ethereum)

In account-based blockchains, a nonce acts as a transaction counter for a specific wallet address. Every time an account
sends a transaction, its nonce increases by one (starting at 0). This ensures transactions are processed in the correct
chronological order and prevents anyone from duplicating or re-submitting a past transaction.
