Setting up a RADIUS (Remote Authentication Dial-In User Service) server at home is a great way to add enterprise-grade
security (like WPA-Enterprise or 802.1X) to your Wi-Fi network, allowing individual user logins instead of a single shared
password.

---

### Step 1: Choose Your Hardware and Software

To run a RADIUS server, you need a device that stays powered on continuously (like a home server, Raspberry Pi, or an old PC)
and software to handle the authentication database.

- **FreeRADIUS:** The industry standard open-source RADIUS server software. It runs natively on Linux (Ubuntu, Debian, or
  Raspberry Pi OS).
- **Alternative (Docker/Containers):** You can also run FreeRADIUS or lightweight alternatives like _RadiusGUI_ inside a
  Docker container for easier management.

---

### Step 2: Install and Configure FreeRADIUS (Linux/Raspberry Pi)

If you are using a Debian-based Linux distribution or a Raspberry Pi, you can install FreeRADIUS via the terminal:

1. Update your system packages:

```bash
sudo apt update && sudo apt upgrade

```

2. Install FreeRADIUS:

```bash
sudo apt install freeradius freeradius-utils

```

#### Configuring Clients and Users

FreeRADIUS needs to know which router/access point is allowed to talk to it (the client) and who is allowed to log in (the
users).

1. **Define the Access Point (`clients.conf`):** Open the configuration file:

```bash
sudo nano /etc/freeradius/3.0/clients.conf

```

Add your home router's IP address and a shared secret password:

```text
client home_router {
    ipaddr = 192.168.1.1     # Replace with your router's IP
    secret = MySecretRadiusPassword
}

```

2. **Add Users (`users` file):** Open the users file to create credentials:

```bash
sudo nano /etc/freeradius/3.0/users

```

Add a user entry with a cleartext password (for testing):

```text
myusername Cleartext-Password := "mypassword123"
    Service-Type = Framed-User

```

3. **Restart FreeRADIUS:** Apply your changes by restarting the service:

```bash
sudo systemctl restart freeradius

```

---

### Step 3: Configure Your Wireless Router

For your home router to use the new RADIUS server, it must support **WPA2/WPA3-Enterprise**:

1. Log into your router's admin panel.
2. Navigate to the Wireless Settings and select **WPA-Enterprise** or **802.1X**.
3. Enter the IP address of your RADIUS server (the Raspberry Pi or home server).
4. Enter the **Port** (default is `1812` for authentication).
5. Enter the exact **Shared Secret** you defined in the `clients.conf` file.

---

### Step 4: Connect Your Devices

When you try to connect a device (like a laptop or phone) to your Wi-Fi network, it will no longer ask for a simple password.
Instead, it will prompt for:

- **Identity / Username** (e.g., `myusername`)
- **Password** (e.g., `mypassword123`)

> **Pro Tip:** For a more user-friendly setup without running a full Linux server, many advanced home routers (such as those
> running **OpenWrt**, or enterprise gear like UniFi and TP-Link Omada) have built-in local RADIUS servers or user databases
> you can toggle on with a few clicks in the dashboard.
