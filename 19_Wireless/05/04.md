**Authentication and Key Management (AKM)** form the backbone of modern wireless network security. While encryption ciphers
(like AES) protect data while it travels through the air, AKM systems control _who_ is allowed onto the network and manage
the secret keys used to lock and unlock that data.

---

### The Two Pillars of AKM

1. **Authentication:** Verifying the identity of a device or user trying to connect to the network.
2. **Key Management:** Generating, distributing, refreshing, and securely destroying the cryptographic keys used for session
   encryption.

---

### How Authentication Works: Personal vs. Enterprise

Modern Wi-Fi networks handle authentication in one of two ways depending on the environment:

- **WPA-Personal (Pre-Shared Key / PSK):** \* Used primarily in homes and small offices.
- Every device uses the same passphrase (the Wi-Fi password) to derive a foundational key called the **PMK (Pairwise Master
  Key)**.

- **WPA-Enterprise (802.1X / EAP):** \* Used in corporate or campus environments.
- Users log in with individual credentials (username/password or digital certificates).
- Authentication is handled by a backend server (like a RADIUS server) using **EAP (Extensible Authentication Protocol)**,
  ensuring every user has a unique identity and unique keys.

---

### Key Management: The 4-Way Handshake

Once a device is authenticated, it must establish unique session keys so that its traffic cannot be decrypted by other users
on the same Wi-Fi network. This is achieved using the **4-Way Handshake**.

The handshake occurs between the client (**Supplicant**) and the router/access point (**Authenticator**) to accomplish three
major goals:

- Prove that both parties possess the correct master key (PMK).
- Generate a fresh, unique session key called the **PTK (Pairwise Transient Key)** used exclusively for encrypting that
  user's unicast data.
- Safely distribute group-wide keys (**GTK**) used for broadcast and multicast messages.

### The Key Hierarchy

To keep a network secure, keys are organized in a strict hierarchy where master keys generate temporary session keys:

- **PMK (Pairwise Master Key):** The master foundation key derived from your password or enterprise server login. It is never
  used directly to encrypt data.
- **PTK (Pairwise Transient Key):** A dynamic, short-lived session key derived from the PMK plus random numbers (nonces)
  generated by both the router and the device. It breaks down into smaller sub-keys used for data encryption, key
  confirmation, and message integrity.
- **GTK (Group Temporal Key):** A shared key managed by the access point to securely send broadcast messages (like network
  routing updates) to all connected devices simultaneously.
