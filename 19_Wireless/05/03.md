Both **RC4 (Rivest Cipher 4)** and **AES (Advanced Encryption Standard)** are symmetric encryption algorithms, meaning they
use the same secret key to both encrypt and decrypt data. However, they are fundamentally different in how they are built,
how they process data, and how secure they are today.

---

### Core Comparison: RC4 vs. AES

| Feature             | RC4 (Rivest Cipher 4)                                                           | AES (Advanced Encryption Standard)                                |
| ------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **Cipher Type**     | **Stream Cipher** (encrypts data bit-by-bit or byte-by-byte).                   | **Block Cipher** (encrypts data in fixed blocks of 128 bits).     |
| **Key Sizes**       | Variable length (typically ranging from 40 to 2048 bits).                       | Fixed lengths: **128, 192, or 256 bits**.                         |
| **Security Status** | **Obsolete / Broken.** Highly vulnerable to statistical attacks and key biases. | **Industry Standard.** Highly secure and heavily vetted globally. |
| **Current Usage**   | Prohibited in modern protocols (deprecated in TLS, WEP, etc.).                  | Used everywhere (HTTPS, Wi-Fi WPA2/WPA3, disk encryption, VPNs).  |

---

### Key Structural Differences

- **How RC4 Works:** RC4 generates a pseudo-random stream of data (a keystream) using a Key Scheduling Algorithm. That
  keystream is then combined with the plaintext using a simple bitwise XOR operation. Because it processes data continuously
  as a stream, it was historically very fast and easy to implement in hardware. However, its keystream has mathematical
  biases, meaning attackers can analyze intercepted traffic and eventually crack the key or recover the original message.
- **How AES Works:** AES takes data and breaks it into structured 128-bit blocks, passing each block through multiple complex
  rounds of substitution, permutation, and mixing (using the Rijndael cipher design). Because it uses fixed blocks and
  multiple mathematical layers, it effectively hides any patterns in the data, making it exceptionally resistant to modern
  cryptanalysis.

---

### Summary Recommendation

- **RC4** should **never** be used in modern software or network designs due to critical vulnerabilities.
- **AES** is the gold standard for symmetric encryption and should always be chosen for securing sensitive data,
  communications, and files.
