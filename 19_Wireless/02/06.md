**Wired Equivalent Privacy (WEP)** is a legacy security protocol designed to secure wireless computer networks. Introduced in
1997, it was intended to provide wireless networks with the same level of confidentiality and security as a traditional wired
network.

However, WEP contains severe architectural flaws and cryptographic weaknesses. Today, it is considered completely obsolete
and insecure, as automated tools can crack a WEP key in a matter of minutes.

---

### Key Vulnerabilities of WEP

WEP's security failures stem from a combination of poor key management, weak encryption implementation, and flawed integrity
checks:

- **Small Initialization Vector (IV):** WEP uses a 24-bit IV combined with a static secret key to encrypt traffic via the RC4
  stream cipher. Because a 24-bit IV is relatively small, values are frequently reused in busy networks, allowing attackers
  to perform statistical analysis.
- **Plaintext IV Transmission:** The IV must be sent in plaintext so the receiver knows how to decrypt the message. This
  exposes vital clues to anyone passively eavesdropping on the network traffic.
- **Static Key Sharing:** WEP relies on a single shared passphrase configured across all devices on the network. Once this
  key is compromised, every device on the network is vulnerable.
- **Weak Integrity Protection (CRC-32):** WEP uses a standard CRC-32 checksum to check data integrity rather than a
  cryptographic message authentication code. This makes the protocol vulnerable to bit-flipping attacks, where data packets
  can be modified in transit without detection.

---

### Common Attacks Against WEP

Because of these design flaws, researchers and malicious actors developed several highly effective methods to compromise
WEP-encrypted networks:

- **FMS Attack (Fluhrer, Mantin, and Shamir):** Published in 2001, this was the first major cryptanalytic attack against WEP.
  It exploits statistical weaknesses in the RC4 key scheduling algorithm. By capturing thousands of packets with weak IVs, an
  attacker can mathematically deduce bytes of the secret key.
- **KoreK and PTW Attacks:** Later optimizations (such as the KoreK and PTW attacks) dramatically improved upon the FMS
  method. The PTW attack, for instance, requires capturing as few as 40,000 packets to successfully recover a 104-bit WEP
  key.
- **Packet Injection and ARP Replay:** In quiet environments where users are not generating much traffic, attackers use
  active techniques like packet injection. By re-injecting intercepted ARP requests, they force the access point (AP) to
  quickly generate a high volume of new responses, accelerating the collection of reusable IVs.
- **Caffe Latte Attack:** This attack targets a client device rather than the access point itself. An attacker near a client
  (even outside the physical range of the AP) can trick the client's wireless card into leaking information, allowing the key
  to be recovered without ever associating with the actual network.

---

### Modern Solutions

Because WEP can be compromised so quickly using standard software tools (such as _Aircrack-ng_), it has long been deprecated
by standards organizations like the IEEE and the Wi-Fi Alliance.

- **WPA / WPA2 / WPA3:** Modern wireless networks utilize Wi-Fi Protected Access protocols, which introduced robust
  encryption standards (like AES), dynamic session keys, and protection against packet injection and statistical attacks.
