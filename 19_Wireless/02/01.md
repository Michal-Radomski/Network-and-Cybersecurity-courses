**Open System Authentication (OSA)** is the default and most basic authentication algorithm defined in the original IEEE
802.11 wireless LAN (WLAN) standard.

Despite its name containing the word "authentication," Open System Authentication essentially performs **no actual identity
verification**. It acts as a "come-one,-come-all" approach where any client device that requests access is automatically
allowed to authenticate, making it completely unverified and unencrypted at the base layer.

---

### How Open System Authentication Works

The authentication process is a simple, mandatory **two-step frame exchange** between a client station (STA) and an Access
Point (AP):

1. **Authentication Request:** The client station sends an 802.11 management frame to the AP stating its desire to connect
   and specifying "Open System" as the chosen authentication algorithm. No passwords, credentials, or keys are provided.
2. **Authentication Response:** The Access Point receives the request and immediately replies with a response frame
   indicating a **success** status code.

Once this quick two-way handshake completes, the client is considered "authenticated" by the 802.11 standard. However,
network access is still not fully active until the subsequent **Association** phase finishes (where the client and AP
exchange capabilities and form a data link).

---

### Key Characteristics

- **No Security on Its Own:** Because there is no credential check, OSA provides zero protection against unauthorized users
  connecting to the wireless medium.
- **Mandatory Support:** Under the 802.11 standard, all wireless devices and access points must support Open System
  Authentication, even if they use higher-layer security protocols later.
- **Common Use Cases:** \* **Public Hotspots:** Used in places like cafes, airports, and hotels where users must connect to
  an open network first before triggering a captive portal (a web page requiring terms-of-service acceptance or credit card
  entry).
- **Modern Encrypted Networks (WPA2/WPA3):** Ironically, modern secure Wi-Fi networks also use Open System Authentication as
  the _initial_ phase. The actual security (passwords or enterprise logins) is handled entirely afterward during the **4-Way
  Handshake** or robust security association (RSN) phase, rendering the open authentication step a mere legacy formality.
