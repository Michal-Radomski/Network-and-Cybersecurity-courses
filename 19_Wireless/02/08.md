### What is SSID Cloaking?

**SSID Cloaking** (often called "hiding your Wi-Fi name") is a configuration setting on a wireless router that stops the
Access Point (AP) from publicly broadcasting its **Service Set Identifier (SSID)**.

Normally, an AP periodically sends out _Beacon frames_ containing the network name so devices within range can see it in
their available networks list. When SSID cloaking is enabled, the router leaves the SSID field blank or null in those beacon
frames, making the network "invisible" to casual users browsing for Wi-Fi.

---

### How It Works

- **Normal Operation:** The router constantly advertises: _"Hello, my name is HomeNetwork."_
- **Cloaked Operation:** The router broadcasts: _"Hello, I am a Wi-Fi network, but I am not telling you my name."_
- **Connecting to a Hidden Network:** Because the name isn't broadcasted, devices cannot automatically see it. To connect, a
  user must manually type the exact SSID and password into their device.

---

### The Security Illusion (Why It Doesn't Work)

In cybersecurity, SSID cloaking is a classic example of **security through obscurity**—relying on secrecy rather than actual
cryptographic strength. Cybersecurity professionals generally consider it ineffective as a primary security measure for
several reasons:

1. **The SSID Still Leaks in Traffic:** Even though the router stops broadcasting the name in beacon frames, devices that
   _already_ know the network must actively search for it. When a smartphone or laptop moves around, it constantly shouts out
   probe requests asking, _"Is HomeNetwork nearby?"_ Anyone running a basic wireless packet analyzer (like Wireshark or
   Kismet) can capture these requests in plain text and instantly discover the hidden name.
2. **Client Probe Vulnerabilities:** When a device actively probes for a hidden network, it reveals its preferred networks to
   anyone listening. Malicious actors can exploit this behavior using rogue access point tools (such as KARMA attacks) to
   trick devices into connecting to a fake network instead.
3. **Usability Drawbacks:** Hiding an SSID makes connecting legitimate devices more tedious and can actually decrease device
   battery life and increase connection latency because clients are forced to constantly perform active radio scans.

---

### Best Practices for Wireless Security

Instead of relying on SSID cloaking to protect a network, modern security standards recommend robust, active measures:

- **Use Strong Encryption:** Always use **WPA2-AES** or **WPA3** encryption rather than legacy protocols like WEP.
- **Strong Passphrases:** Choose long, complex Wi-Fi passwords to prevent brute-force attacks.
- **Keep Firmware Updated:** Regularly install router updates to patch newly discovered vulnerabilities.
- **Network Segmentation:** Separate sensitive computers from IoT (smart home) devices using guest networks or VLANs.
