While people often use the words "password," "passphrase," and "key" interchangeably in casual conversation, they mean very
different things under the hood in wireless network engineering.

The core distinction is that a **password** is what _you_ type (human-readable), while a **key** is a mathematically
processed string of bits that the computer and router actually use to lock and unlock data.

---

### 1. WEP: The Static Key (No True Password)

In legacy **WEP (Wired Equivalent Privacy)**, there is technically no "password" translation process.

- **What you enter:** You manually configure a strict sequence of hexadecimal digits (e.g., `1A2B3C4D5E`) or a 5-character
  ASCII word directly into the device.
- **What it is:** This string _is_ the raw encryption key. Because it never changes (it's static) and is shared by every
  device, anyone capturing network packets can eventually mathematically reverse it.

---

### 2. WPA2 and WPA3: Password vs. Pre-Shared Key (PSK) vs. Session Keys

In modern protocols like **WPA2-Personal** and **WPA3-Personal**, your human-friendly Wi-Fi password goes through
mathematical transformations to become actual security keys.

| Term                            | What it is                                                                                                                                                                                                  | Example / Function                                                                                                                                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Wi-Fi Password / Passphrase** | The human-friendly string of 8 to 63 characters that you type into your phone or laptop to join the Wi-Fi.                                                                                                  | `"MySuperSecretPassword123"`                                                                                                                                                                         |
| **Pre-Shared Key (PSK) / PMK**  | A mathematically derived 256-bit binary key. Your device takes your typed password, combines it with your router's network name (SSID), and runs it through a hashing function (PBKDF2) thousands of times. | The resulting code (the **Pairwise Master Key**) is stored on your device and the router so they both know the other person belongs there.                                                           |
| **Session / Encryption Keys**   | Temporary, unique keys generated _fresh_ every single time a device connects using a process called the **4-Way Handshake**.                                                                                | These keys encrypt your actual web traffic and change periodically or per session, ensuring that even if someone figures out your main Wi-Fi password later, they can't easily decrypt past traffic. |

---

### Summary Comparison Table

| Feature            | WEP Key                                                     | WPA2 / WPA3 Password & Keys                                                              |
| ------------------ | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **User Input**     | Manual hex code or simple ASCII string.                     | Human-readable passphrase (8–63 characters).                                             |
| **Transformation** | None—the input _is_ the active encryption key.              | Input is hashed with the network name (SSID) to create a master key (PSK/PMK).           |
| **Key Lifespan**   | **Static:** Stays identical forever until manually changed. | **Dynamic:** Master key creates temporary, changing session keys via a secure handshake. |
| **Security Level** | Completely broken; easily cracked in minutes.               | Highly secure against offline cracking (especially WPA3's SAE handshake).                |
