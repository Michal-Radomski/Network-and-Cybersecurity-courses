### What is a Static WEP Key?

A **static WEP key** is a fixed, manually configured secret password used in legacy Wired Equivalent Privacy (WEP) networks
to encrypt and decrypt data packets.

Unlike modern Wi-Fi protocols that automatically generate fresh, temporary encryption keys for every session or device, a
static WEP key remains completely identical over time. Every single device (laptops, phones, access points) on that network
must be manually programmed with the exact same character string (usually entered as a 10 or 26-digit hexadecimal code, or a
5 or 13-character ASCII string). If any device has a single character wrong, it cannot communicate with the network.

---

### Why is it "Static"?

The word **static** means stationary, fixed, or unchanging. In the context of cryptography and network security, it describes
a key with specific vulnerabilities:

- **It Never Changes Automatically:** A dynamic key changes frequently (e.g., every few minutes or per session) to prevent
  attackers from accumulating enough data to crack it. A static key stays active indefinitely until a network administrator
  manually logs in and changes it.
- **It Is Shared Universally:** Because every user on the network uses the exact same static key to talk to the Access Point,
  compromise is absolute. If one employee or device shares the key, or if an attacker steals it from a single device, the
  entire network's security is instantly broken for everyone.
- **It Causes Reused Key Streams:** In WEP, the combination of a static key and a short, repeating 24-bit Initialization
  Vector (IV) means that the underlying math (the RC4 keystream) eventually repeats itself. Because the key never changes, an
  attacker just needs to wait and passively capture enough traffic until those duplicate patterns appear, allowing them to
  mathematically reverse-engineer the static key in minutes.
