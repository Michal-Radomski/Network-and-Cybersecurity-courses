### Initialization Vector (IV)

An **Initialization Vector (IV)** is a pseudo-random value used alongside a secret encryption key to encrypt data packets in
a wireless network.

- **Purpose:** Stream ciphers (like the RC4 cipher used in legacy WEP) generate a continuous stream of random numbers to mix
  with plaintext data. If the exact same secret key is used repeatedly with the same sequence, the encryption output becomes
  predictable and easily breakable. Adding an IV changes the starting "seed" for every single packet, ensuring that two
  identical messages sent across the network encrypt into completely different ciphertexts.
- **The Vulnerability in Legacy Systems:** In old WEP networks, the IV was only **24 bits** long. Because 24 bits is a
  relatively small number (yielding about 16.7 million combinations), busy networks would quickly exhaust all available IVs
  and start repeating them. Furthermore, the IV was sent out in **cleartext** (unencrypted) alongside the packet data.
  Hackers could capture these repeating IVs and easily mathematical-reverse the key, cracking the network. Modern protocols
  (like WPA2 and WPA3) use significantly larger IVs (such as 48-bit or 104-bit counters) combined with robust encryption
  block ciphers (AES) to eliminate this flaw entirely.

### Robust Security Network (RSN)

A **Robust Security Network (RSN)** is a secure wireless local area network architecture defined by the IEEE 802.11i
amendment (which was later integrated into the core Wi-Fi standard and popularized commercially as **WPA2** and **WPA3**).

An RSN was created specifically to replace the flawed and insecure WEP framework by establishing a strict, robust security
framework.

#### Core Features of an RSN:

- **Robust Security Network Association (RSNA):** An RSNA is the secure logical connection established between a client
  station and an Access Point after going through a rigorous mutual authentication process.
- **The 4-Way Handshake:** Unlike legacy systems that used static, unchanging passwords, an RSN uses a dynamic cryptographic
  process called the **4-Way Handshake**. This safely derives unique, temporary encryption keys for every single session or
  client without ever sending the actual password over the air.
- **Advanced Encryption Ciphers:** An RSN mandates or supports strong modern cryptographic ciphers:
- **CCMP (Counter Mode with Cipher Block Chaining Message Authentication Code Protocol)**, which relies on the military-grade
  **AES** (Advanced Encryption Standard) encryption.
- **TKIP** (a legacy transition protocol used in early WPA, now also deprecated).
