**CCMP** stands for **Counter-Mode/CBC-MAC Protocol**. It is the robust, highly secure encryption protocol introduced to
replace the vulnerable TKIP and WEP standards. CCMP is the core encryption mechanism used by **WPA2** and serves as the
foundation for modern Wi-Fi security.

### 1. Purpose and Background

- **The AES Standard:** Unlike TKIP (which relied on the flawed RC4 stream cipher), CCMP is built entirely around the **AES
  (Advanced Encryption Standard)** block cipher, specifically utilizing a 128-bit key length.
- **WPA2 Integration:** CCMP was introduced alongside WPA2 in 2004 to provide enterprise-grade and home-grade wireless
  networks with ironclad data confidentiality, integrity, and authenticity.
- **Hardware Requirements:** Because AES requires significantly more computational power than legacy WEP hardware, CCMP
  generally required dedicated hardware acceleration built into Wi-Fi network interface cards (NICs) and routers.

---

### 2. Core Architectural Components

CCMP combines two distinct cryptographic techniques into a single, highly efficient mode of operation:

- **Counter Mode (CTR):** Provides strong data **confidentiality** (encryption). It turns a block cipher into a stream cipher
  by encrypting a sequence of "counters" to generate a key stream that is XORed with the plaintext data.
- **CBC-MAC (Cipher Block Chaining Message Authentication Code):** Provides **data integrity** and authenticity. It ensures
  that data packets cannot be intercepted, modified, or forged in transit without detection.

---

### 3. Structure of a CCMP MPDU

Similar to TKIP, CCMP adds overhead to every standard 802.11 MAC Protocol Data Unit (MPDU) to secure the frame, though its
structure is completely different and far more secure.

```
+-------------------+-------------------+-------------------+-------------------+
| 802.11 MAC Header |    CCMP Header    |   Payload (MSDU)  |      MIC          |
|    (Variable)     |     (8 Bytes)     |   (Variable)      |     (8 Bytes)     |
+-------------------+-------------------+-------------------+-------------------+

```

#### 1. 802.11 MAC Header (Modified)

- Contains standard layer-2 fields. Certain bits and subfields (such as QoS control fields) are managed carefully to ensure
  the security mechanisms do not break normal wireless routing.

#### 2. CCMP Header (8 Bytes Added)

- **Packet Number (PN - 6 bytes):** Functions as a strict sequence counter (similar to TKIP's sequence counter). It
  increments with every packet sent to prevent **replay attacks**.
- **Reserved/Flags (2 bytes):** Used for protocol management and specifying user priority.

#### 3. Payload / MSDU

- The actual data being transmitted, which is fully encrypted using AES-CTR mode.

#### 4. Message Integrity Code / MIC (8 Bytes Added)

- Generated by the CBC-MAC algorithm over the unencrypted MAC header, the CCMP header, and the payload. This acts as an
  unforgeable cryptographic seal. If a single bit of the packet is altered during transmission, the receiving device's MIC
  check will fail, and the packet will be instantly dropped.

---

### Why CCMP Replaced TKIP

- **Mathematical Strength:** While researchers eventually found ways to exploit theoretical weaknesses in TKIP, AES-CCMP
  remains cryptographically sound and secure against modern decryption and key-recovery attacks.
- **Performance:** Modern processors feature dedicated hardware instructions for AES (such as AES-NI on CPUs and specialized
  hardware blocks in Wi-Fi chips), meaning CCMP runs exceptionally fast with minimal latency impact.

_(Note: In modern Wi-Fi 6, Wi-Fi 6E, and Wi-Fi 7 networks using **WPA3**, CCMP is often supplemented or superseded by
**GCMP**—Galois/Counter Mode Protocol—which provides even faster performance and higher security for multi-gigabit wireless
links.)_
