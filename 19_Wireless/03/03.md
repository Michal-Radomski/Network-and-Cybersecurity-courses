**Simultaneous Authentication of Equals (SAE)** is a secure password-authenticated key exchange protocol. It is most famously
used in the **WPA3-Personal** Wi-Fi security standard, where it replaced the older, more vulnerable Pre-Shared Key (PSK)
method used in WPA2.

SAE is designed to let two parties (such as your smartphone and a Wi-Fi router) establish a secure connection using a shared
password without actually transmitting that password over the air.

---

### Key Features and Security Benefits

- **Mutual Authentication:** Both the device connecting to the network and the access point prove to each other that they
  possess the correct password.
- **Resistance to Offline Dictionary Attacks:** In older WPA2 systems, an attacker could capture the initial connection
  handshake over the air and then take it offline to endlessly guess passwords (a dictionary attack) until they found the
  right one. SAE prevents this by ensuring that an attacker cannot use captured traffic to test password guesses offline.
  Every connection attempt requires a live interaction with the network.
- **Forward Secrecy:** Even if someone manages to discover the Wi-Fi password at a later date, they still cannot use it to
  decrypt past recorded network traffic.

---

### How It Works: The Dragonfly Handshake

At the heart of SAE is a mechanism called the **Dragonfly handshake** (based on a variant of the Diffie-Hellman key
exchange).

1. **Password Mapping:** Instead of sending the plain text password or a direct hash of it, the protocol uses the password to
   map a secret point onto a mathematical curve (either a cyclic group or an elliptic curve).
2. **Independent Proofs:** Both the client device and the router simultaneously generate and exchange cryptographic tokens
   based on this curve point.
3. **Key Derivation:** If both parties successfully verify each other's tokens, they independently compute a strong, unique
   session key used to encrypt the connection. The actual password is never exposed during any part of this exchange.
