**WireGuard** is a modern VPN protocol designed to create a **secure, encrypted network tunnel** between two devices.

For your previous question about connecting two routers, WireGuard can be used instead of IPsec to create a **site-to-site
VPN**.

### Simple example

```text
Site A                                      Site B
192.168.1.0/24                              192.168.2.0/24

PC ── Router A ═══════ Internet ═══════ Router B ── PC
                    WireGuard tunnel
```

A computer at `192.168.1.50` could communicate with a computer at `192.168.2.50` through the encrypted WireGuard tunnel.

### Why WireGuard is popular

- 🔐 **Strong encryption** — uses modern cryptographic algorithms.
- ⚡ **Fast** — designed to have low overhead and high performance.
- 🧩 **Simple configuration** — generally much easier to configure than traditional IPsec.
- 🖥️ **Cross-platform** — available on Linux, Windows, macOS, Android, iOS, and many routers/firewalls.
- 🔑 **Public/private keys** — devices authenticate using cryptographic keys rather than usernames/passwords.
- 🌐 **Works well through NAT** — useful when one or both sites are behind ordinary Internet routers.

### WireGuard vs. IPsec

|                  | WireGuard           | IPsec              |
| ---------------- | ------------------- | ------------------ |
| Configuration    | ⭐ Simple           | More complex       |
| Performance      | Excellent           | Excellent          |
| Security         | Modern              | Very mature        |
| Authentication   | Public/private keys | PSK/certificates   |
| Site-to-site VPN | ✅ Yes              | ✅ Yes             |
| Router support   | Increasingly common | Extremely common   |
| Troubleshooting  | Usually easier      | Can be complicated |

One important distinction: **WireGuard is a VPN protocol, not a complete VPN service**. You can run WireGuard directly on
routers, servers, PCs, etc.

For a **two-router site-to-site VPN**, WireGuard is often an excellent choice if both routers support it.
