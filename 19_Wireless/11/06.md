### What is LDAP?

**LDAP (Lightweight Directory Access Protocol)** is a standard software protocol used for locating, organizing, and accessing
user information, passwords, and security permissions across a centralized network database.

Think of LDAP as a digital phonebook for your organization. Instead of creating a separate username and password for every
single application, file server, or printer, administrators store all user credentials in one central directory. When a user
tries to log into a system, that system asks the LDAP database to verify who the user is.

---

### How LDAP Works

1. **Directory Structure:** LDAP organizes data in a hierarchical, tree-like structure called a **Directory Information Tree
   (DIT)**. It groups information logically using attributes like countries, organizations, organizational units, and common
   names.
2. **Client-Server Model:** Applications (clients) send queries to an LDAP server (such as Microsoft Active Directory or
   OpenLDAP) to request information or authenticate a user.
3. **Bindings and Queries:** \* **Bind:** The process of a client authenticating itself to the LDAP server.

- **Search/Modify:** The client queries the database for user details or requests changes to records.

---

### Key Components of an LDAP Entry

Every piece of data in an LDAP directory is an entry identified by a unique address called a **Distinguished Name (DN)**. A
DN acts like a complete file path for an object. For example:

`cn=John Doe,ou=Engineering,dc=company,dc=com`

- **CN (Common Name):** The specific name of the user or object (e.g., John Doe).
- **OU (Organizational Unit):** The department or group the user belongs to (e.g., Engineering).
- **DC (Domain Component):** The parts of the organization's domain name (e.g., company.com broken into `dc=company` and
  `dc=com`).

---

### Common Use Cases

- **Single Sign-On (SSO):** Allowing employees to use one primary username and password to log into their computer, email,
  enterprise applications, and internal websites.
- **Network Security & Access Control:** Quickly verifying which security groups or permissions a user belongs to before
  granting access to specific files or network folders.
- **Address Books:** Powering corporate email directories so users can auto-complete colleague names and email addresses in
  clients like Microsoft Outlook.
