### What is SNMP?

**SNMP (Simple Network Management Protocol)** is a standard communication protocol used for monitoring, managing, and
maintaining network devices—such as routers, switches, servers, printers, and access points—from a centralized location.

It acts as a common language that allows different hardware from various manufacturers to report their health, status, and
performance metrics back to an IT administrator.

---

### How SNMP Works

SNMP operates on a **manager-agent model**:

1. **The SNMP Manager:** A central monitoring server (running software like PRTG, Zabbix, or Nagios) that requests
   information or listens for alerts from network devices.
2. **The SNMP Agent:** A small piece of software or firmware built into network devices (like your switch or router) that
   collects local data and stores it in a database.
3. **The Management Information Base (MIB):** A hierarchical database structure that defines what variables and data points a
   device can measure (e.g., CPU utilization, temperature, bandwidth usage, or error rates).

---

### Key SNMP Operations

- **GET:** The manager requests a specific piece of information from an agent (e.g., _"What is the current CPU temperature of
  this switch?"_).
- **SET:** The manager commands an agent to change a configuration setting (e.g., _"Shut down this specific port"_).
- **TRAP:** An unsolicited alert sent by the agent to the manager when a predefined event or threshold is triggered (e.g.,
  _"Warning: Power supply failure!"_ or _"Interface went down!"_).

---

### Core Versions

- **SNMPv1:** The original version; very simple, but lacks security because data and community strings (passwords) are sent
  in plain text.
- **SNMPv2c:** An update that added better performance and bulk data retrieval, but still suffered from poor security (plain
  text community strings).
- **SNMPv3:** The current standard, which introduces robust security features including cryptographic authentication and
  encryption to protect network data from eavesdropping and tampering.
