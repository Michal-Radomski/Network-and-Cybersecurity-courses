Setting up **OpenLDAP** (the open-source implementation of LDAP) on Ubuntu involves installing the server package, running
through the initial configuration wizard to establish your base directory structure, and verifying the installation.

---

### Step 1: Update Your System and Install OpenLDAP

Open your terminal and make sure your package lists are up to date, then install **slapd** (the standalone LDAP daemon) and
**ldap-utils** (client utility tools):

```bash
sudo apt update
sudo apt install slapd ldap-utils

```

During the installation process, a configuration prompt will appear asking you to:

1. Enter an **administrator password** for your OpenLDAP directory.
2. Confirm the password.

---

### Step 2: Reconfigure the OpenLDAP Server

If you skipped any prompts or want to define your specific domain naming structure, you can trigger the configuration wizard
manually at any time:

```bash
sudo dpkg-reconfigure slapd

```

Follow the prompts carefully:

- **Omit OpenLDAP server configuration?** Select **No**.
- **DNS domain name:** Enter your domain name (e.g., `example.com`). This will automatically dictate your Base Distinguished
  Name (Base DN). For example, `example.com` becomes `dc=example, dc=com`.
- **Organization name:** Enter your organization's name (e.g., `example`).
- **Administrator password:** Enter and confirm your secure password.
- **Database backend:** Choose **MDB** (the modern default backend).
- **Remove the database when slapd is purged?** Select **No**.
- **Move old database?** Select **Yes** (if prompted to clear out any legacy configuration).

---

### Step 3: Verify the Installation

Once configured, verify that the LDAP service is active and running smoothly:

```bash
sudo systemctl status slapd

```

You can also run a basic search query using the built-in client utilities to test connectivity to your newly created
directory:

```bash
ldapsearch -Q -LLL -Y EXTERNAL -H ldapi:/// -b dc=example,dc=com

```

_(Note: Replace `dc=example,dc=com` with the specific Base DN you set up during the re-configuration step.)_ If successful,
this command will output the initial structure of your directory tree.
