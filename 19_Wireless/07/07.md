**PMKID** stands for **Pairwise Master Key Identifier**. It is a specific data element defined in the IEEE 802.11i (WPA2)
standard that functions as a cryptographic label for a **PMKSA** (Pairwise Master Key Security Association).

---

## How PMKID is Generated

Unlike the PMK itself—which is derived directly from your Wi-Fi password (PSK) or an enterprise authentication server—the
PMKID is calculated by the Access Point (AP) using a deterministic formula:

$$\text{PMKID} = \text{HMAC-SHA1-128}(\text{PMK}, \text{"PMK Name"} \parallel \text{MAC}_{\text{AP}} \parallel \text{MAC}_{\text{Client}})$$

Because it incorporates the MAC addresses of both the access point and the client device, along with a standardized string
identifier, it creates a unique fingerprint for that specific connection session.

---

## What is the PMKID Used For?

1. **Identifying Security Contexts:** It allows the client and the AP to quickly refer to a shared security association
   without transmitting the actual Master Key over the air.
2. **Fast Roaming and Re-authentication:** When a device reconnects or moves between access points in a managed network,
   presenting the PMKID lets the system verify that a valid session already exists, skipping lengthy re-authentication steps.
3. **Robust Security Network (RSN) Handshake:** It is typically sent out in the very first frame of connection negotiations
   (the RSN Information Element) to signal compatibility and state.

---

## Security Context and Vulnerabilities

In network security discussions, PMKID is frequently referenced due to a known vulnerability discovered in 2018:

- **The Vulnerability:** Many access point manufacturers configured their firmware to automatically generate and send a PMKID
  when an association request is made—even before a client fully authenticates or completes a 4-way handshake.
- **The Risk:** Because the PMKID is derived mathematically from the network's passphrase (or Pre-Shared Key), security
  researchers and penetration testers realized they could capture a single frame containing the PMKID directly from an AP and
  run an **offline brute-force attack** to guess the Wi-Fi password, eliminating the need to capture a live client's 4-way
  handshake.

Modern network configurations mitigate this by ensuring firmware handles RSN information securely and by using robust,
complex passwords that resist offline cracking attempts.
