**Mobile IP** (Internet Protocol) is a communications protocol designed by the Internet Engineering Task Force (IETF). It
allows a mobile device—such as a laptop, smartphone, or tablet—to move from one network to another while keeping its
**permanent IP address** and maintaining ongoing connections (like video calls, downloads, or VPN sessions) without dropping
them.

---

### Why is Mobile IP Needed?

Normally, internet routers deliver data based on a device's fixed geographic and network location, much like sending mail to
a physical street address. If you move your computer to a completely different network (like switching from your home Wi-Fi
to a coffee shop's Wi-Fi), your IP address changes. When that happens, standard TCP connections break, and active
applications crash.

Mobile IP solves this problem by ensuring that even as your device moves around, your sessions stay alive.

---

### Key Components of Mobile IP

To make this work seamlessly behind the scenes, Mobile IP relies on a few core players:

- **Mobile Node (MN):** The portable device (like your phone or laptop) that is moving between different networks.
- **Home Address (HoA):** The permanent IP address assigned to the mobile device on its home network, which never changes.
- **Home Agent (HA):** A router located on the device’s home network. It acts as an anchor point, keeping track of where the
  device is when it leaves home and intercepting data meant for it.
- **Foreign Network:** Any network that the mobile device visits away from home.
- **Foreign Agent (FA):** A router on the visited foreign network that assists the mobile node by providing routing services
  and temporary addressing.
- **Care-of Address (CoA):** A temporary IP address assigned to the mobile device while it is connected to a foreign network.
  It tells the Home Agent where to forward data.
- **Correspondent Node (CN):** Any regular computer or server on the internet that is communicating with the mobile device.

---

### How Mobile IP Works (Step-by-Step)

When a mobile device leaves its home network, the communication process happens in three primary stages:

1. **Agent Discovery:** \* The Mobile Node listens for periodic announcement messages sent out by routers to figure out
   whether it is still on its home network or if it has moved to a foreign network.
2. **Registration:** \* If the device realizes it is on a foreign network, it acquires a **Care-of Address (CoA)**.

- It then sends a registration message to its **Home Agent**, letting it know: _"Hey, I am currently visiting this foreign
  network, and here is my temporary address."_

3. **Tunneling and Forwarding:** \* When a **Correspondent Node** sends data to the mobile device's permanent Home Address,
   the data first arrives at the **Home Agent**.

- Because the Home Agent knows the device is away, it **tunnels** the data (packages it inside a new IP packet) and forwards
  it across the internet directly to the device's temporary Care-of Address (or via the Foreign Agent).
- The Foreign Agent (or the device itself, depending on the setup) strips away the outer wrapper and delivers the original
  data to the mobile device.

---

### Real-World Relevance

While modern cellular networks (like 4G and 5G) use their own internal handoff mechanisms to keep you connected as you move
between cell towers, Mobile IP is heavily utilized in enterprise environments, virtual private networks (VPNs), and
situations where devices need to switch seamlessly between different types of wireless networks (such as jumping between
Wi-Fi hotspots and satellite or WiMAX links).
