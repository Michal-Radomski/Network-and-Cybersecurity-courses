**PMKSA** stands for **Pairwise Master Key Security Association**. In wireless networking (IEEE 802.11), it is a temporary
security context established between a wireless client (like a smartphone or laptop) and an access point (AP) or
authentication server.

---

## What is a PMKSA?

When a device connects to a secure Wi-Fi network using 802.1X/EAP authentication or a pre-shared key (PSK), it goes through
an initial authentication process. A successful exchange creates a **Pairwise Master Key (PMK)**.

The **PMKSA** binds that PMK to specific entities, storing information such as:

- The **PMK** (the root master key used to derive encryption keys).
- The **PMKID** (a unique identifier for that specific security association).
- The MAC addresses of the client and the authenticator (AP).

---

## Why is PMKSA Important? (Fast Roaming)

The primary role of a PMKSA is to allow **fast and secure roaming** when moving between multiple access points in an
enterprise or large network.

Without a PMKSA, every time your device roams to a new access point, it would have to go through a full, time-consuming
authentication process (such as a full 802.1X handshake with a backend RADIUS server). This can cause noticeable delays,
dropping VoIP calls or lagging video streams.

### How PMK Caching Works

1. **Initial Connection:** The client authenticates with AP-1 and a PMKSA is created and cached on both the device and the
   network.
2. **Roaming:** When the client moves and tries to connect to AP-2 (within the same network), it references the cached PMKSA
   using its **PMKID**.
3. **Skipping Authentication:** If AP-2 recognizes the PMKSA (or shares it via a controller/mobility group), the client can
   skip the heavy 802.1X authentication process entirely.
4. **4-Way Handshake:** The client and AP-2 jump straight to the **4-Way Handshake** to generate fresh session keys,
   drastically reducing roaming time to milliseconds.
