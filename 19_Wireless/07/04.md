A **Wireless Distribution System (WDS)** is a technology that enables the interconnection of wireless access points (APs) in
an IEEE 802.11 network. It allows you to expand a wireless network using multiple access points **without needing a
traditional wired Ethernet backbone** to link them together.

---

## How WDS Works

Traditionally, every wireless access point must be connected to a physical network cable linked to a router. With WDS, access
points can communicate and pass data through the air.

Roles within a WDS network typically include:

- **Main (Root) Base Station:** Usually connected directly to the wired Internet or primary router.
- **Relay Base Station:** Receives data wirelessly from the main station (or another relay) and passes it along to extend the
  range further.
- **Remote Base Station:** Accepts connections from wireless clients (like phones and laptops) and forwards their traffic
  into the WDS chain.

---

## Common WDS Topologies

- **Point-to-Point Bridging:** Connects two specific access points together to bridge two separate network segments (often
  used to connect two nearby buildings).
- **Point-to-Multipoint Bridging:** A central "hub" access point connects to multiple remote access points simultaneously.

---

## Advantages and Limitations

| Advantages                                                                                                                             | Limitations                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No Cabling Required:** Great for historical buildings, outdoor areas, or spaces where running physical wires is difficult or costly. | **Throughput Reduction:** Because access points must transmit client data _and_ relay data to other APs on the same radio channel, wireless speeds can be halved for every "hop" (retransmission). |
| **MAC Address Preservation:** Preserves original client MAC addresses across the wireless links.                                       | **Compatibility Issues:** Standards for WDS were never tightly formalized in the 802.11 specification, meaning equipment from different manufacturers often fail to work together.                 |
| **Seamless Roaming:** Allows users to move around a large area without dropping connection or re-authenticating.                       | **Security Limits:** Many WDS implementations only support older or static encryption keys (like WEP or static WPA-PSK), restricting dynamic enterprise security protocols.                        |

> **Note:** While WDS was popular for DIY network expansion using older consumer routers, modern setups often lean toward
> **Mesh Wi-Fi systems**, which handle multi-node wireless routing, automatic channel optimization, and modern security
> protocols much more seamlessly.
