Hash cracking is the process of guessing the plaintext input that matches a specific cryptographic hash value. Because secure
cryptographic hashes are one-way mathematical functions that cannot be "reversed" or decrypted, cracking relies on guessing
millions or billions of text variations, running them through the target hashing algorithm, and checking if the resulting
output matches the target hash. [1, 2] Security professionals and attackers use several core methods to accomplish this. [1,
3]

## Core Hash Cracking Methods

- Dictionary Attack: Tests a list of pre-compiled words, common phrases, and leaked credentials (such as the famous
  rockyou.txt wordlist). [1, 2, 4]
- Rule-Based Attack: Modifies dictionary words using custom patterns to replicate human behavior, such as capitalizing the
  first letter, changing letters to numbers (e.g., "password" to "p4ssw0rd"), or appending symbols and years (e.g.,
  "Summer2026!"). [2, 3]
- Brute-Force Attack: Systematically tries every possible combination of characters within a set length (e.g., testing every
  1 to 8 character permutation of lowercase letters and numbers). [2, 4]
- Mask Attack: A targeted brute-force method where the attacker specifies known patterns of the password to save time, such
  as forcing the first letter to be uppercase, followed by five lowercase letters, and ending with two numbers
  (?u?l?l?l?l?l?d?d). [3]
- Rainbow Table Attack: Compares the target hash against massive precomputed databases containing millions of plaintext
  passwords and their corresponding hash outputs. This instantly reveals the plaintext if a match is found, but it is
  rendered useless if the target hash is salted. [4, 5]
- Hybrid Attack: Combines multiple approaches simultaneously, such as taking a dictionary word and running a short
  brute-force sequence directly after it. [1, 3]

## Common Tools Utilized

- [Hashcat](https://hashcat.net/hashcat/): Widely considered the world's fastest password-recovery tool. It is heavily
  optimized for GPU acceleration, which allows standard graphics cards to test billions of combinations per second. [3, 6, 7,
  8]
- John the Ripper: A highly versatile tool optimized primarily for CPUs. It excels at automatically detecting hash formats
  and handling complex, customized rule scripting. [1, 9]
- CrackStation: A popular web-based lookup tool that utilizes massive precomputed tables and dictionaries to find matches for
  unsalted hashes instantly. [10]

## Defenses Against Hash Cracking

To protect system credentials against these highly effective cracking methods, developers and administrators implement
several structural defenses: [8]

- Salting: Adding a unique, random string of data (a salt) to each password before it is hashed. This ensures identical
  passwords yield entirely different hashes, rendering rainbow tables useless.
- Key Stretching: Utilizing slow, resource-heavy hashing algorithms specifically built for credentials. Modern standards like
  Argon2 and bcrypt force the hardware to spend massive computational time and memory on a single guess, reducing a GPU's
  cracking speed from billions of attempts per second to just a few thousand. [3, 4, 5, 11]
