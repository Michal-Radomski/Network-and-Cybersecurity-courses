### Security Risks of WPA2 and WPA3

While Wi-Fi Protected Access (WPA2 and WPA3) security protocols protect wireless networks from unauthorized access, both
protocols possess distinct vulnerabilities and risks that attackers can exploit.

---

### 1. Risks of WPA2 (Wi-Fi Protected Access 2)

WPA2 has been the industry standard for Wi-Fi security for nearly two decades, but its age means several fundamental flaws
have been uncovered.

- **The KRACK Vulnerability (Key Reinstallation Attack):** \* Discovered in 2017, KRACK targets the 4-way handshake used by
  WPA2 to establish a secure connection.
- An attacker can trick a device into reinstalling an already-in-use encryption key, allowing them to intercept, decrypt, or
  manipulate network traffic (such as injecting malware into websites).

- **Vulnerability to Offline Brute-Force Attacks:** \* On residential or standard networks using **WPA2-PSK (Pre-Shared
  Key)**, an attacker who captures the initial handshake over the air can take it offline and attempt to guess the password
  using brute-force methods without alerting the network administrator.
- **Weak Enterprise Implementations (WPA2-Enterprise):** \* When WPA2-Enterprise relies on older authentication methods like
  PEAP (Protected Extensible Authentication Protocol) without proper certificate validation, it becomes vulnerable to rogue
  access point attacks (Evil Twin attacks), where users unknowingly send their credentials to an attacker's device.

---

### 2. Risks of WPA3 (Wi-Fi Protected Access 3)

Introduced to fix the security shortcomings of WPA2—particularly regarding password guessing—WPA3 brought major upgrades like
SAE (Simultaneous Authentication of Equals), but new implementation flaws have since been discovered.

- **Dragonblood Vulnerabilities:** \* Discovered shortly after WPA3's release, Dragonblood is a suite of flaws affecting
  WPA3's handshake mechanism.
- It allowed attackers to perform **downgrade attacks** (forcing a network to use WPA2) or launch side-channel and
  cache-based timing attacks to recover the network password via offline computation, undermining the initial promise of
  absolute immunity to brute-forcing.

- **Wi-Fi Easy Connect Flaws (ANSSI Findings):** \* Research highlighted vulnerabilities in Wi-Fi Easy Connect (meant to
  simplify IoT device onboarding using QR codes), showing that improper implementation could allow attackers to bypass
  authentication or gain unauthorized network access.
- **Implementation and Deployment Lag:** \* Many enterprise and consumer routers implement WPA3 with **Transition Mode**
  (allowing both WPA2 and WPA3 devices to connect simultaneously). This backward compatibility leaves networks vulnerable to
  attacks targeting the weaker WPA2 fallback layer.
- **Denial of Service (DoS) Risks:** \* Some WPA3 handshake mechanisms can be targeted by resource exhaustion attacks, where
  malicious actors flood an access point with connection requests, preventing legitimate users from connecting.

---

### Summary Comparison of Protocol Risks

| Protocol | Primary Security Weakness                           | Attack Method                                                      |
| -------- | --------------------------------------------------- | ------------------------------------------------------------------ |
| **WPA2** | Predictable handshakes and weak key management      | Offline dictionary/brute-force attacks; KRACK traffic interception |
| **WPA3** | Implementation flaws in complex handshake protocols | Side-channel attacks; Downgrade attacks via Transition Mode        |
