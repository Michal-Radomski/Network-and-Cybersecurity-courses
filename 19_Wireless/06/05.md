**Wi-Fi Protected Setup (WPS)** is a network security standard created by the Wi-Fi Alliance in 2006. Its primary purpose is
to make it easy for non-technical users to connect new wireless devices (like printers, smart TVs, or phones) to a secure
home network without having to manually type out a long, complex Wi-Fi password.

---

### How WPS Works

WPS typically relies on one of a few connection methods:

1. **Push-Button Configuration (PBC):** The user presses a physical or virtual button on the Wi-Fi router, and then presses a
   button or activates the feature on the connecting device. The two devices securely talk to each other and exchange
   credentials during a short, temporary window (usually about two minutes).
2. **PIN Method:** The router or device displays an 8-digit Personal Identification Number (PIN), which the user enters into
   the configuration menu to establish the connection.
3. **Near Field Communication (NFC) / USB:** Users tap their NFC-enabled device near the router or use a USB flash drive to
   transfer network settings (largely legacy methods now).

---

### Why WPS is a Major Security Risk

While convenient, **PIN-based WPS has critical design flaws** that render even the strongest WPA2 or WPA3 network passwords
vulnerable.

- **Flawed PIN Validation:** Instead of checking all 8 digits of the WPS PIN at once (which would take millions of
  combinations and make brute-forcing impossible), the WPS protocol splits the PIN into two separate halves and validates
  them independently.
- **Reduced Combination Space:** Because the last digit is just a checksum and the router validates the first half separately
  from the second half, an attacker only has to test a maximum of **11,000 combinations** rather than 100 million.
- **Automated Brute-Forcing:** Using specialized tools (such as _Reaver_ or _Bully_), an attacker within radio range can
  systematically guess these combinations via automated scripts. Within hours (or sometimes minutes), they can successfully
  crack the WPS PIN.
- **Password Disclosure:** Once an attacker successfully cracks the WPS PIN, the router automatically hands over the actual
  network Wi-Fi password to them, completely bypassing the security of your main passphrase.
- **The Pixie Dust Attack:** Certain router chipsets suffer from weak random number generation during the WPS handshake. This
  allows attackers to capture a single connection exchange and calculate the WPS PIN **offline** in mere seconds without
  triggering router lockouts.

---

### Best Practice Recommendation

Because of these inherent vulnerabilities, cybersecurity experts and agencies like CISA strongly recommend **disabling WPS
completely** in your router's administrative settings, especially if the PIN method is active. Relying on manually entering a
strong passphrase or using secure device onboarding ensures your wireless network remains fully protected.
