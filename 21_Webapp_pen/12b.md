Here is an example of how to securely handle data deserialization in JavaScript and Node.js.

To prevent vulnerabilities like prototype pollution or unexpected object injection, you should rely on native JSON parsing
combined with strict schema validation to ensure incoming data strictly conforms to expected structures.

---

### Secure Deserialization Example with Schema Validation

Using a validation library like **Zoi** or **Ajv** ensures that any unauthorized or dangerous keys (such as `__proto__`) are
rejected or stripped out before your application processes the object.

```javascript
const { z } = require("zod");

// 1. Define a strict schema for the expected data structure
const userSchema = z.object({
  username: z.string().min(3).max(20),
  email: z.string().email(),
  age: z.number().int().positive(),
});

function parseSecureData(rawJsonString) {
  try {
    // 2. Parse using native JSON.parse() (safe from code execution)
    const parsedData = JSON.parse(rawJsonString);

    // 3. Validate and sanitize against the strict schema
    // This automatically strips out unexpected properties (like __proto__)
    const validatedData = userSchema.parse(parsedData);

    return { success: true, data: validatedData };
  } catch (error) {
    // Handle parsing or validation failures safely
    return { success: false, error: "Invalid data format or structure." };
  }
}

// Example usage:
const maliciousInput = '{"username": "alice", "email": "alice@example.com", "age": 25, "__proto__": {"isAdmin": true}}';

const result = parseSecureData(maliciousInput);
console.log(result);
// Output will contain only the valid properties:
// { success: true, data: { username: 'alice', email: 'alice@example.com', age: 25 } }
// The dangerous '__proto__' property is completely stripped out.
```

---

### Key Takeaways for Secure Deserialization

- **Stick to `JSON.parse()`:** Never use custom, unmaintained serialization libraries that attempt to serialize functions,
  classes, or complex object graphs.
- **Validate Schemas:** Always validate incoming payloads against a predefined schema (using tools like Zod, Joi, or Ajv) to
  ensure keys and data types match expectations.
- **Strip Unknown Keys:** Configure your parsers or validators to strip out unrecognized keys to prevent prototype pollution
  and unexpected state injection.
