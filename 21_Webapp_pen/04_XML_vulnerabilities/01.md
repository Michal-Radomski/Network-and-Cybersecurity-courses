XML vulnerabilities occur when applications process untrusted XML input using weakly configured XML parsers. Because XML
standards include powerful features like Document Type Definitions (DTDs), external entity resolution, and XPath queries,
insecure parsers can be exploited for data theft, denial of service (DoS), and internal network compromise.

---

### Key XML Vulnerabilities

**1. XML External Entity (XXE) Injection** XXE occurs when an XML parser evaluates external entity declarations inside a
Document Type Definition (`<!DOCTYPE>`). Attackers inject malicious URIs or file paths into these entities.

- **File Disclosure:** Reading local system files (e.g., `/etc/passwd` or application config files).
- **Server-Side Request Forgery (SSRF):** Forcing the server to send HTTP/TCP requests to internal infrastructure (cloud
  metadata endpoints, internal APIs).
- **Port Scanning:** Probing internal network addresses to discover unexposed services.

```xml
<!-- Example XXE Payload reading a local file -->
<!DOCTYPE data [
  <!ENTITY file SYSTEM "file:///etc/passwd">
]>
<user><name>&file;</name></user>

```

---

**2. XML Bomb / Exponential Entity Expansion (Billion Laughs)** A denial-of-service attack that uses nested XML entities.
When the parser resolves the recursively defined entities, it expands exponentially in memory, rapidly exhausting server RAM
and crashing the process.

```xml
<!-- Example XML Bomb -->
<!DOCTYPE lolz [
  <!ENTITY lol "lol">
  <!ENTITY lol1 "&lol;&lol;&lol;&lol;&lol;&lol;&lol;&lol;&lol;&lol;">
  <!ENTITY lol2 "&lol1;&lol1;&lol1;&lol1;&lol1;&lol1;&lol1;&lol1;&lol1;&lol1;">
]>
<data>&lol2;</data>

```

---

**3. XPath Injection** Similar to SQL Injection, XPath injection occurs when untrusted user input is directly concatenated
into an XPath query string used to query XML documents.

- **Impact:** Bypassing authentication, extracting hidden XML nodes, or modifying administrative parameters.

---

**4. XML Quadratic Blowup** Similar to an XML Bomb, but relies on a single large entity repeated multiple times in the
document (linear payload structure expanding quadratically on parsing) rather than nested entity definitions.

---

### Core Mitigation Strategies

| Defense Mechanism             | Action Required                                                                                                                     |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Disable DTDs**              | Completely turn off inline Document Type Definitions (`<!DOCTYPE>`) in your XML parser settings.                                    |
| **Disable External Entities** | Set parser flags to ignore `SYSTEM` and `PUBLIC` external entities (`external-general-entities` and `external-parameter-entities`). |
| **Use Safe Data Formats**     | Migrate to JSON or protocol buffers where possible for API payload processing.                                                      |
| **Parameterized Queries**     | Use parameterized/pre-compiled XPath queries rather than dynamic string concatenation.                                              |
