### What is Xorshift128+?

**Xorshift128+** is a fast pseudo-random number generator (PRNG) algorithm designed to produce sequences of random numbers
efficiently. It combines the **Xorshift** technique (which uses bitwise shift and XOR operations for speed) with an
**add-based multiplier ("+")** to improve its statistical properties.

Because of its high speed and small memory footprint, variations of Xorshift128+ have historically been used by JavaScript
engines (like Google Chrome's V8 engine) to power functions like `Math.random()`.

---

### Why is it Not Secure?

While Xorshift128+ performs well for non-critical tasks (like simulations, games, or UI rendering), it is **cryptographically
insecure** for several reasons:

#### 1. Predictable Internal State

Xorshift128+ relies on a fixed-size internal state (128 bits, split into two 64-bit values). Because the mathematical
operations used to transform this state are linear and deterministic, the algorithm is entirely reversible.

#### 2. State Recovery from Outputs

An attacker who can observe a small, consecutive sequence of outputs generated by Xorshift128+ can use linear algebra and
bitwise equations to mathematically solve for the generator's internal state. Once the state is uncovered, the attacker can
accurately predict:

- **All future random numbers** the application will produce.
- **All past random numbers** the application previously produced.

#### 3. Lack of Cryptographic Hardening

Cryptographically Secure Pseudo-Random Number Generators (CSPRNGs) require protection against state-recovery attacks (often
using cryptographic hash functions or operating system entropy). Xorshift128+ lacks these protections, making it unsuitable
for generating security tokens, password resets, or session IDs.
