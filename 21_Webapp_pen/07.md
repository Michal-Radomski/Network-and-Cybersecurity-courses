Adding a CAPTCHA to a React and Node.js application helps protect your forms (like login, signup, or contact forms) from spam
and bots. A popular and user-friendly option is **Google reCAPTCHA (v2 or v3)** or **hCaptcha**.

Here is a step-by-step guide to integrating **Google reCAPTCHA v2 ("I'm not a robot" checkbox)** into your full-stack app.

---

### Step 1: Register Your Site

1. Go to the [Google reCAPTCHA Admin Console](https://www.google.com/recaptcha/admin).
2. Register a new site and choose **reCAPTCHA v2** ("I'm not a robot" Checkbox).
3. Add your domain (use `localhost` for local development).
4. Once registered, you will receive two keys:

- **Site Key** (used in your React frontend)
- **Secret Key** (used in your Node.js backend)

---

### Step 2: Frontend Setup (React)

1. Install a popular React reCAPTCHA library:

```bash
npm install react-google-recaptcha

```

2. Implement the component in your form:

```jsx
import React, { useState } from "react";
import ReCAPTCHA from "react-google-recaptcha";

function SignupForm() {
  const [captchaValue, setCaptchaValue] = useState(null);
  const [formData, setFormData] = useState({ username: "", password: "" });

  const handleCaptchaChange = (value) => {
    // Value is the token generated by Google upon successful completion
    setCaptchaValue(value);
  };

  const handleSubmit = async (e) => {
    e.preventDefault();

    if (!captchaValue) {
      alert("Please complete the CAPTCHA");
      return;
    }

    // Send data along with the captcha token to your backend
    const response = await fetch("http://localhost:5000/api/signup", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ ...formData, captchaToken: captchaValue }),
    });

    const data = await response.json();
    console.log(data);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" placeholder="Username" onChange={(e) => setFormData({ ...formData, username: e.target.value })} />
      <input
        type="password"
        placeholder="Password"
        onChange={(e) => setFormData({ ...formData, password: e.target.value })}
      />

      {/* Google reCAPTCHA Component */}
      <ReCAPTCHA sitekey="YOUR_REACT_APP_SITE_KEY" onChange={handleCaptchaChange} />

      <button type="submit">Submit</button>
    </form>
  );
}

export default SignupForm;
```

---

### Step 3: Backend Setup (Node.js / Express)

You must verify the token sent from the frontend on your server by making a secure POST request to Google's verification
endpoint. This prevents users from bypassing the frontend check.

1. Install `axios` or use native `fetch` (Node 18+) to make the verification request:

```bash
npm install express cors

```

2. Set up your Express route:

```javascript
const express = require("express");
const cors = require("cors");
const app = express();

app.use(express.json());
app.use(cors());

const SECRET_KEY = "YOUR_NODE_SECRET_KEY";

app.post("/api/signup", async (req, res) => {
  const { username, password, captchaToken } = req.body;

  if (!captchaToken) {
    return res.status(400).json({ success: false, message: "Captcha token is required" });
  }

  try {
    // Verify the token with Google
    const verificationUrl = `https://www.google.com/recaptcha/api/siteverify?secret=${SECRET_KEY}&response=${captchaToken}`;

    const response = await fetch(verificationUrl, { method: "POST" });
    const googleResponse = await response.json();

    if (!googleResponse.success) {
      return res.status(400).json({ success: false, message: "Failed CAPTCHA verification" });
    }

    // CAPTCHA is valid! Proceed with user registration (e.g., save to database)
    console.log("User registered:", username);

    return res.status(200).json({ success: true, message: "Successfully registered!" });
  } catch (error) {
    console.error("Error verifying captcha:", error);
    return res.status(500).json({ success: false, message: "Internal server error" });
  }
});

app.listen(5000, () => {
  console.log("Server running on port 5000");
});
```

---

### Best Practices

- **Environment Variables:** Never hardcode your Site Key or Secret Key in your source code. Use `.env` files
  (`REACT_APP_SITE_KEY` for React and `CAPTACH_SECRET` for Node.js).
- **Server-Side Verification:** Always verify the token on the backend. Frontend validation alone can be easily bypassed by
  tech-savvy users or bots.
