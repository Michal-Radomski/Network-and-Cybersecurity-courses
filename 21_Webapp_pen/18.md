Modern programming languages and frameworks use several built-in mechanisms to eliminate or severely reduce memory-related
vulnerabilities like buffer overflows.

Here is how modern technology stacks protect your code from memory corruption:

### 1. Automatic Garbage Collection

- **How it works:** In older languages like C or C++, developers have to manually allocate (`malloc`) and free (`free`)
  memory. Forgetting to free memory or freeing it incorrectly leads to security flaws.
- **The Modern Fix:** Languages like Java, C#, Go, and JavaScript use **garbage collectors** that automatically track and
  clean up unused memory in the background, eliminating entire classes of memory management bugs.

### 2. Built-in Bounds Checking

- **How it works:** A buffer overflow happens when a program tries to write data past the end of an array.
- **The Modern Fix:** Modern runtimes and languages automatically perform bounds checking. If a script or application tries
  to read or write outside the allocated size of an array or string, the runtime catches it immediately and throws an error
  (like an `IndexOutOfBoundsException`) rather than quietly corrupting adjacent memory.

### 3. Type Safety and Memory Safety

- **Type Safety:** Languages like TypeScript (which builds on JavaScript) enforce strict data types. You cannot accidentally
  treat a piece of text as a raw memory address, which prevents attackers from manipulating pointers.
- **Memory-Safe Languages:** Even newer systems-level languages like **Rust** have revolutionized safety by introducing a
  strict "borrow checker" at compile-time. Rust guarantees memory safety without needing a garbage collector, making it
  impossible to have buffer overflows or use-after-free bugs in safe Rust code.

### 4. Framework and Compiler Protections

- **Safe APIs:** Modern web frameworks and libraries abstract away direct memory manipulation. Developers interact with
  high-level data structures (like maps, lists, and safe strings) rather than raw pointers.
- **Compiler Hardening:** Modern compilers (like GCC, Clang, or the MSVC compiler used in the Node.js/V8 toolchain) include
  automatic security features such as **Stack Canaries** (which detect if a stack has been overflowed before a function
  returns) and **Address Space Layout Randomization (ASLR)**, which randomizes where code sits in memory to make exploits
  much harder to pull off.
