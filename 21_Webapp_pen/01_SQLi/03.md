**sqlmap** is an open-source penetration testing tool that automates the process of detecting and exploiting SQL injection
flaws and taking over database servers. It supports a wide range of database management systems (DBMS), including MySQL,
PostgreSQL, Oracle, Microsoft SQL Server, SQLite, and MariaDB.

---

**Core Capabilities**

- **Automated Injection Testing:** Supports all six major SQL injection techniques: Boolean-based blind, Time-based blind,
  Error-based, UNION query-based, Stacked queries, and Out-of-band.
- **Database Fingerprinting & Enumeration:** Automatically identifies the backend database type and version, retrieves
  databases, tables, columns, user accounts, and password hashes.
- **Data Extraction:** Allows automated dumping of entire database tables or specific columns into local files.
- **System Takeover:** Given sufficient privileges, sqlmap can execute arbitrary commands on the underlying operating system
  via functions like `xp_cmdshell` (MS SQL) or `sys_eval()` (MySQL), or open an interactive shell connection.
- **File System Access:** Supports downloading and uploading files directly to/from the target database server.

---

**Common Command Usage**

Basic vulnerability scan against a GET parameter:

```bash
sqlmap -u "http://target.com/page.php?id=1" --batch

```

Parsing a full HTTP request saved from a proxy (like Burp Suite) to test headers, cookies, or POST bodies:

```bash
sqlmap -r request.txt --dbs

```

Extracting data from a confirmed vulnerable endpoint:

```bash
# Dump tables from a specific database
sqlmap -u "http://target.com/page.php?id=1" -D app_db --tables

# Dump data from a target table
sqlmap -u "http://target.com/page.php?id=1" -D app_db -T users --dump

```
