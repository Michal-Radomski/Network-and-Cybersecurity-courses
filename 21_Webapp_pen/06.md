**OWASP DirBuster** is a multi-threaded Java application designed to perform brute-force discovery of hidden directories and
files on web servers. Penetration testers use wordlists to send sequential requests and discover unlinked admin panels,
backup files, and hidden endpoints.

---

### How to Install DirBuster on Ubuntu

DirBuster requires a Java Runtime Environment (JRE).

1. **Update System & Install Java:** Prerequisite. Open your terminal and install OpenJDK:

```bash
sudo apt update
sudo apt install default-jre -y

```

2. **Download DirBuster Package:** Download the official package archive directly from SourceForge via `wget`:

```bash
wget https://downloads.sourceforge.net/project/dirbuster/DirBuster%20%28Version%201.0-RC1%29/DirBuster-1.0-RC1/DirBuster-1.0-RC1.tar.bz2

```

3. **Extract the Archive:** Unpack the downloaded archive:

```bash
tar -xjvf DirBuster-1.0-RC1.tar.bz2
cd DirBuster-1.0-RC1

```

4. **Launch DirBuster:** Execute the startup script or run the JAR file directly:

```bash
./DirBuster-1.0-RC1.sh
# Alternatively: java -jar DirBuster-1.0-RC1.jar

```

### How to Use DirBuster (Basic Workflow)

Once launched, the graphical user interface (GUI) appears:

1. **Target URL:** Enter your target URL including protocol and port (e.g.,
   `[http://192.168.1.50:8080/](http://192.168.1.50:8080/)` or `[https://example.com/](https://example.com/)`).
2. **Number of Threads:** Set thread count (default is `10`; increase to `20`–`50` for faster local scans, but keep low for
   slow/remote servers).
3. **Select Wordlist:** Click **Browse** next to _File with list of dirs/files_. DirBuster includes default wordlists inside
   its directory:

- Recommended: `./directory-list-2.3-medium.txt`
- SecLists alternative (if installed): `/usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt`

4. **File Extensions:** Specify extensions to look for (e.g., `php, html, txt, json, bak`).
5. **Start Scan:** Click **Start** at the bottom right. Results populate in real-time under the **Results - List View** or
   **Results - Tree View** tabs.

### Modern Alternatives

_Note: OWASP DirBuster is a legacy project (last officially updated in 2009). While functional, CLI-based tools are
significantly faster and lighter:_

| Tool            | Speed                   | Interface | Installation Command        |
| --------------- | ----------------------- | --------- | --------------------------- |
| **ffuf**        | Extremely fast          | CLI       | `sudo apt install ffuf`     |
| **gobuster**    | Fast (Go-based)         | CLI       | `sudo apt install gobuster` |
| **feroxbuster** | High performance (Rust) | CLI       | `cargo install feroxbuster` |
