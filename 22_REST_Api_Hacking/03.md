## What is a REST API?

A **REST API** (Representational State Transfer Application Programming Interface) is a set of rules and conventions used to
build web services. It allows different software applications to talk to each other over the internet using standard HTTP
requests.

Think of a REST API like a waiter in a restaurant:

1. You (the **client** / frontend app) look at the menu and place an order.
2. The waiter (the **API**) takes your order to the kitchen (the **server** / database).
3. The kitchen prepares the food and gives it back to the waiter, who then brings your meal back to you.

---

## Core Concepts of REST

To be considered "RESTful," an API must follow a specific set of architectural constraints and concepts:

- **Statelessness:** The server does not store any state about the client session. Every request from the client must contain
  all the information necessary for the server to understand and fulfill it.
- **Client-Server Architecture:** The user interface (client) and the data storage/backend logic (server) are kept separate.
  This allows either part to evolve independently.
- **Uniform Interface:** A standardized way of interacting with resources, making the API predictable and easy to use.
- **Resources:** Everything in REST is viewed as a "resource" (e.g., users, products, messages). Each resource is identified
  by a unique URL, known as an **Endpoint** (e.g., `/api/users/123`).

---

## HTTP Methods (The Actions)

REST APIs use standard HTTP methods to perform operations on resources. These are often mapped to **CRUD** operations
(Create, Read, Update, Delete):

- **GET:** Retrieve a resource (Read). _Example: Fetching a user's profile data._
- **POST:** Create a new resource (Create). _Example: Signing up for a new account._
- **PUT / PATCH:** Update an existing resource (Update). `PUT` typically replaces the whole resource, while `PATCH` applies
  partial updates. _Example: Changing your password._
- **DELETE:** Remove a resource (Delete). _Example: Deleting a post or comment._

---

## Data Formats

While REST APIs can technically return data in various formats (like HTML or XML), **JSON (JavaScript Object Notation)** is
by far the most popular and standard format today because it is lightweight, human-readable, and easy for programming
languages to parse.
