## What is `express.urlencoded()`?

`express.urlencoded()` is a built-in middleware function in **Express.js**.

It is used to parse incoming requests with **URL-encoded payloads**—which is the standard format browsers use to send data
from HTML `<form>` elements when submitted via a `POST` request.

---

### How It Works

When a user submits an HTML form, the data is sent in the HTTP request body encoded like this (querystring format):
`name=John+Doe&age=25&city=New+York`

By default, Express does not parse this raw body data. If you try to read `req.body`, it will be `undefined`. Adding
`express.urlencoded()` allows your server to read that data and turn it into a usable JavaScript object so you can access it
via `req.body.name`, `req.body.age`, etc.

---

### Key Configuration Option

You usually see it implemented with an option like this:

```javascript
app.use(express.urlencoded({ extended: true }));
```

- **`extended: false`**: Uses the `querystring` library, which parses the URL-encoded data using a simple, traditional
  algorithm (cannot handle nested objects).
- **`extended: true`**: Uses the `qs` library, which allows for rich and complex objects and nested data structures to be
  parsed from the URL-encoded format.
