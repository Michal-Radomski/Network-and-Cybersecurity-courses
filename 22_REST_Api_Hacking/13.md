To limit the number of login attempts to a REST API and protect against brute-force attacks, developers use a technique
called **Rate Limiting**.

In an Express.js API, the most common and effective way to do this is by using the popular `express-rate-limit` package. This
acts as a security guard that tracks how many requests come from a specific IP address or user account and blocks them if
they try too many times.

---

### Example: Implementing a Login Rate Limiter in Express

1. **Install the package:**

```bash
npm install express-rate-limit

```

2. **Configure and apply it to your login route:**

```javascript
const express = require("express");
const rateLimit = require("express-rate-limit");

const app = express();
app.use(express.json());

// Create a strict rate limiter for the login route
const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 minutes time window
  max: 5, // Limit each IP to 5 login attempts per window
  message: {
    error: "Too many login attempts, please try again after 15 minutes.",
  },
  standardHeaders: true, // Return rate limit info in the headers
  legacyHeaders: false, // Disable the X-RateLimit-* headers
});

// Apply the limiter specifically to the POST /api/login endpoint
app.post("/api/login", loginLimiter, (req, res) => {
  const { username, password } = req.body;

  // Your normal login validation logic goes here...
  res.send("Login attempt processed.");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
```

---

### Best Practices for Login Throttling

- **Target the IP and the Username:** Simple IP rate limiting can sometimes block multiple legitimate users if they share a
  network (like a corporate office or school Wi-Fi). Advanced systems combine IP tracking with the target username so that an
  attacker guessing passwords for _one_ account gets blocked without locking out other users on the same network.
- **Respond with Status Code `429`:** When a limit is breached, the server automatically responds with HTTP status code **429
  Too Many Requests**, informing legitimate clients that they need to wait before trying again.
