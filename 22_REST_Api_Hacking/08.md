## What is XML External Entity (XXE) Injection?

**XML External Entity Injection (XXE)** is a web security vulnerability that occurs when an application parses XML input from
an untrusted source and allows the inclusion of external entities.

XML is a markup language used to structure data. It allows the definition of "entities," which are essentially variables or
shortcuts used within the XML document. An _external_ entity tells the parser to load data from an external source—such as a
local file on the server or a URL on the internet. If an XML parser is misconfigured to process these external references, an
attacker can manipulate the XML input to read local files, execute internal network requests, or cause a denial of service.

---

## XXE in Express.js APIs

By default, **Express.js does not parse XML**. Out of the box, Express apps typically handle JSON (`express.json()`) or
URL-encoded data (`express.urlencoded()`).

However, an Express.js API can become vulnerable to XXE if a developer:

1. Accepts XML data as input from clients (e.g., via a custom body parser or third-party middleware).
2. Uses an insecure or legacy XML parsing library to read that data.
3. Leaves the parser's default settings enabled, which often permit the loading of external entities and DTDs (Document Type
   Definitions).

---

## How to Prevent XXE

Securing an application against XXE involves proper configuration of the XML parser or avoiding XML entirely:

- **Disable External Entities and DTDs:** If your application must accept XML, configure your XML parser to explicitly
  disable the processing of DTDs and external entities. Most modern XML parsing libraries have options like `noent: false` or
  flags to ignore external resources.
- **Use Safer Data Formats (JSON):** Whenever possible, design APIs to use **JSON** instead of XML. JSON does not support
  external entities or DTDs, completely eliminating the risk of XXE injection.
- **Keep Dependencies Updated:** Regularly update any third-party parsing libraries to ensure known security patches are
  applied.
