To send XML data to an Express.js API instead of JSON, you need to configure both the **client** (the sender) and the
**server** (Express) to handle the XML format properly, since Express doesn't parse XML by default.

---

### Step 1: Configure the Express Server

Because Express does not natively parse XML request bodies, you can use a community middleware package like
`express-xml-bodyparser` or use `express.text()` combined with an XML parser like `xml2js`.

Using **`express-xml-bodyparser`** is the easiest approach:

1. Install the package via terminal:

```bash
npm install express-xml-bodyparser

```

2. Set it up in your Express app:

```javascript
const express = require("express");
const xmlparser = require("express-xml-bodyparser");

const app = express();

// Enable XML body parsing middleware
app.use(xmlparser());

app.post("/api/data", (req, res) => {
  // req.body will automatically contain the parsed XML as a JavaScript object
  console.log(req.body);
  res.send("XML received and parsed successfully!");
});

app.listen(3000);
```

---

### Step 2: Send XML from the Client

When making an HTTP request from a client (such as a frontend application using `fetch` or a tool like Postman), you must
explicitly set the **`Content-Type` header to `application/xml**`(or`text/xml`) and pass the payload as a raw XML string.

#### Example using JavaScript `fetch()`:

```javascript
const xmlData = `
<note>
    <to>Tania</to>
    <from>John</from>
    <heading>Reminder</heading>
    <body>Don't forget the meeting!</body>
</note>
`;

fetch("http://localhost:3000/api/data", {
  method: "POST",
  headers: {
    "Content-Type": "application/xml", // Crucial: Tells Express what format to expect
  },
  body: xmlData,
})
  .then((response) => response.text())
  .then((data) => console.log(data))
  .catch((error) => console.error("Error:", error));
```

---

### Key Security Reminder

As discussed earlier, if your server accepts XML, ensure your XML parser is configured securely to **disable DTDs (Document
Type Definitions) and external entities** to prevent **XXE (XML External Entity)** injection attacks.
