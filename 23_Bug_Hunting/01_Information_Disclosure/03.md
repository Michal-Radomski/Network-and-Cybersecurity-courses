## Securing HTTP Headers with `helmet`

By default, an Express application in Node.js sends response headers like `X-Powered-By: Express`. This tells potential
attackers exactly what framework your server is built on, making it easier for them to target known vulnerabilities.

The **Helmet** package is an essential tool that helps secure your Express apps by setting various HTTP headers
automatically. It hides server details and protects against common web vulnerabilities.

### 1. Installation

Install `helmet` via your terminal using npm:

```bash
npm install helmet

```

### 2. Implementation in Express

Integrating `helmet` is straightforward—you just mount it as middleware early in your application pipeline:

```javascript
const express = require("express");
const helmet = require("helmet");

const app = express();

// Automatically secure HTTP headers across the entire app
app.use(helmet());

app.get("/", (req, res) => {
  res.send("This app is protected by Helmet!");
});

app.listen(3000, () => {
  console.log("Server is running safely on port 3000");
});
```

### What `helmet` Does Behind the Scenes

- **Removes `X-Powered-By`:** Hides the fact that your server is running Express.
- **Sets Strict-Transport-Security (HSTS):** Enforces secure (HTTPS) connections to the server.
- **Sets X-Content-Type-Options:** Prevents browsers from MIME-sniffing a response away from the declared content-type.
- **Sets X-Frame-Options:** Protects your application against clickjacking attacks.
