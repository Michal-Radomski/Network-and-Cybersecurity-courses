Preventing **Open Redirect vulnerabilities** in a React application typically involves ensuring that any user-controlled URL
parameters—often fetched via `react-router-dom` search parameters or `window.location`—are strictly validated before
navigating the user.

---

### How Open Redirects Happen in React

In React, developers often extract a redirect path from the URL query string to send users back to their intended page after
logging in:

```javascript
// UNSAFE EXAMPLE
import { useSearchParams } from "react-router-dom";

function Login() {
  const [searchParams] = useSearchParams();
  const redirectTo = searchParams.get("redirect");

  const handleLogin = () => {
    // If redirectTo is "https://malicious-site.com", the user is sent there!
    window.location.href = redirectTo;
  };
}
```

---

### Best Practices for Prevention

#### 1. Enforce Relative Paths

The safest way to handle redirects within your own application is to ensure the destination starts with a single forward
slash (`/`) and does not point to an external domain or protocol (like `//malicious.com`).

```javascript
const isSafeRedirect = (url) => {
  // Must start with '/' but not '//' or 'http://'
  return url && url.startsWith("/") && !url.startsWith("//");
};
```

#### 2. Implement a Strict Domain Whitelist

If your application genuinely needs to redirect users to external partner sites or subdomains, validate the target URL
against an explicit, hardcoded list of approved domains using the native `URL` API.

```javascript
const ALLOWED_DOMAINS = ["app.example.com", "help.example.com"];

const isValidExternalUrl = (url) => {
  try {
    const parsedUrl = new URL(url, window.location.origin);
    return ALLOWED_DOMAINS.includes(parsedUrl.hostname);
  } catch (e) {
    // Invalid URL format
    return false;
  }
};
```

#### 3. Implement a Safe Redirection Handler

Combine your validation checks into a helper function before triggering navigation via `react-router-dom` or
`window.location`:

```javascript
import { useNavigate, useSearchParams } from "react-router-dom";

function SafeRedirectComponent() {
  const [searchParams] = useSearchParams();
  const navigate = useNavigate();

  const handleNavigation = () => {
    const rawRedirect = searchParams.get("redirect") || "/dashboard";

    // Validate that the path is safe
    if (isSafeRedirect(rawRedirect)) {
      navigate(rawRedirect);
    } else {
      // Fallback to a safe default route
      navigate("/dashboard");
    }
  };
}
```
