To include a quotation mark inside a JavaScript string, you have a few simple options depending on the type of quotes you are
using for the string itself:

## 1. Use Alternative Quotes

If your string is wrapped in double quotes, you can use single quotes inside it (and vice versa):

```javascript
let message1 = 'He said, "Hello!"';
let message2 = "It's a wonderful day.";
```

---

## 2. Escape the Quote (Backslash)

If you need to use the **same** type of quote inside the string as the ones wrapping it, you must "escape" it by placing a
backslash (`\`) right before it:

```javascript
let message1 = 'He said, "Hello!" to everyone.';
let message2 = "It's a wonderful day.";
```

---

## 3. Use Template Literals (Backticks)

You can use template literals (backticks ` ` `) to create strings. They allow you to include both single and double quotes
directly without escaping:

```javascript
let message = `He said, "It's a wonderful day!"`;
```
