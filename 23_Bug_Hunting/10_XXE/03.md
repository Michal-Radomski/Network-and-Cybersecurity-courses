Here is the difference between XML, HTML, and SVG, broken down by what they are designed to do:

---

### 1. XML (Extensible Markup Language)

- **What it is:** A general-purpose language used to store, transport, and structure data.
- **Key feature:** XML does not have predefined tags. You create your own tags based on what data you are storing (e.g.,
  `<student><name>Alex</name></student>`).
- **Main Use:** Data interchange between different software systems (often used in APIs, configuration files, and RSS feeds).

### 2. HTML (HyperText Markup Language)

- **What it is:** A specific markup language designed for creating and structuring web pages.
- **Key feature:** HTML has a standardized set of predefined tags recognized by web browsers (e.g., `<h1>`, `<p>`, `<a>`,
  `<img>`).
- **Main Use:** Telling a web browser how to display text, links, and layout elements on a website.

### 3. SVG (Scalable Vector Graphics)

- **What it is:** An image format used to display two-dimensional vector graphics (like icons, logos, and charts) on the web.
- **Key feature:** Because SVG is actually **written in XML**, it is made of code rather than pixels. This means you can
  scale an SVG to any size without it getting blurry or losing quality, and you can style it using CSS or manipulate it with
  JavaScript.
- **Main Use:** Creating sharp, responsive graphics and animations for websites.

---

### Summary of How They Relate

Think of **XML** as the parent framework for storing data, **SVG** as a specialized child of XML used specifically for
drawing vector images, and **HTML** as a completely separate language used for structuring web pages.
