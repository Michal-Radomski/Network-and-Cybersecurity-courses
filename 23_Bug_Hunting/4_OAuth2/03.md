Implementing OAuth 2.0 in a **React (Frontend)** and **Node.js/Express (Backend)** application is typically done using the
**Authorization Code Flow**.

Having a Node.js backend is a huge advantage because it allows you to securely store your **Client Secret** on the server,
keeping it hidden from the browser. Below is a step-by-step guide on how to build this integration using a popular provider
like Google (or an identity provider like Auth0/FusionAuth).

---

### Step 1: Set Up an OAuth Provider (e.g., Google Cloud Console)

1. Go to the Google Cloud Console and create a new project.
2. Configure your **OAuth consent screen** (add your app name and email).
3. Create **Credentials** -> **OAuth client ID**, selecting **Web application**.
4. Set your **Authorized redirect URIs** to point to your Node.js backend:

- `http://localhost:5000/auth/google/callback` (Assuming Node runs on port 5000).

5. Copy your **Client ID** and **Client Secret**.

---

### Step 2: Node.js & Express Backend Setup

Your backend will handle the secure communication with the OAuth provider and manage user sessions.

1. **Install dependencies:**

```bash
npm install express passport passport-google-oauth20 express-session cors dotenv

```

2. **Configure the Server (`server.js`):** Using **Passport.js** simplifies handling OAuth strategies in Node.js.

```javascript
const express = require("express");
const passport = require("passport");
const GoogleStrategy = require("passport-google-oauth20").Strategy;
const session = require("express-session");
const cors = require("cors");
require("dotenv").config();

const app = express();

// 1. Configure Session
app.use(
  session({
    secret: "your_session_secret",
    resave: false,
    saveUninitialized: false,
  })
);

app.use(
  cors({
    origin: "http://localhost:3000", // React frontend URL
    credentials: true,
  })
);

app.use(passport.initialize());
app.use(passport.session());

// 2. Configure Passport Google Strategy
passport.use(
  new GoogleStrategy(
    {
      clientID: process.env.GOOGLE_CLIENT_ID,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET,
      callbackURL: "/auth/google/callback",
    },
    (accessToken, refreshToken, profile, done) => {
      // Here, you typically save or find the user in your database
      return done(null, profile);
    }
  )
);

passport.serializeUser((user, done) => done(null, user));
passport.deserializeUser((user, done) => done(null, user));

// 3. Auth Routes
app.get("/auth/google", passport.authenticate("google", { scope: ["profile", "email"] }));

app.get(
  "/auth/google/callback",
  passport.authenticate("google", { failureRedirect: "http://localhost:3000/login" }),
  (req, res) => {
    // Successful authentication, redirect back to React app dashboard
    res.redirect("http://localhost:3000/dashboard");
  }
);

// Endpoint for React to check current auth state
app.get("/api/current-user", (req, res) => {
  if (req.isAuthenticated()) {
    res.json(req.user);
  } else {
    res.status(401).json({ error: "Unauthorized" });
  }
});

app.get("/auth/logout", (req, res) => {
  req.logout(() => {
    res.redirect("http://localhost:3000/login");
  });
});

app.listen(5000, () => console.log("Server running on port 5000"));
```

---

### Step 3: React Frontend Setup

Your React frontend doesn't handle tokens directly; instead, it redirects the user to the backend login route and checks user
session status via cookies.

1. **Create Login and Dashboard components:**

```jsx
// Login.jsx
import React from "react";

export default function Login() {
  const handleLogin = () => {
    // Redirect browser to Node.js backend OAuth route
    window.location.href = "http://localhost:5000/auth/google";
  };

  return (
    <div>
      <h2>Login to App</h2>
      <button onClick={handleLogin}>Sign in with Google</button>
    </div>
  );
}
```

2. **Check Authentication Status on Load (`App.jsx` or Dashboard):** Make sure to include `credentials: 'include'` in API
   fetches so the browser sends the session cookie back to Express.

```jsx
import React, { useEffect, useState } from "react";

export default function Dashboard() {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch("http://localhost:5000/api/current-user", {
      credentials: "include", // Crucial for sending/receiving cookies
    })
      .then((res) => {
        if (res.ok) return res.json();
        throw new Error("Not authenticated");
      })
      .then((data) => {
        setUser(data);
        setLoading(false);
      })
      .catch(() => {
        setLoading(false);
      });
  }, []);

  if (loading) return <div>Loading...</div>;
  if (!user)
    return (
      <div>
        Please log in <a href="http://localhost:5000/auth/google">here</a>.
      </div>
    );

  return (
    <div>
      <h2>Welcome, {user.displayName}</h2>
      <p>Email: {user.emails[0].value}</p>
      <a href="http://localhost:5000/auth/logout">Logout</a>
    </div>
  );
}
```

---

### Summary of the Request Flow

1. **User clicks "Login with Google"** in React $\rightarrow$ browser navigates to `http://localhost:5000/auth/google`.
2. **Node.js redirects** the user to Google's Authorization Server.
3. **User logs into Google** and grants permission.
4. **Google redirects back** to Node.js backend callback route with an authorization code.
5. **Node.js backend trades code** for access tokens behind the scenes using the hidden _Client Secret_, creates a secure
   session, and sets a cookie on the browser.
6. **Node redirects browser** back to React (`/dashboard`), which queries the backend API (`/api/current-user`) to render
   user details using that session cookie.
