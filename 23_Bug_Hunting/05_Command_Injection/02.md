Preventing command injection in Node.js involves avoiding functions that execute commands through a system shell (like
`exec`) and instead using safer alternatives that treat arguments as literal data (like `execFile` or `spawn`), combined with
strict input validation.

Here is how you can implement these preventions in **TypeScript**.

---

### 1. The Vulnerable Approach (What to Avoid)

Never concatenate user input directly into a shell command string.

```typescript
import { exec } from "child_process";

// DANGEROUS: If userInput contains '; rm -rf /', it will be executed by the shell
function runInsecurePing(userInput: string) {
  exec(`ping -c 1 ${userInput}`, (error, stdout, stderr) => {
    if (error) {
      console.error(`Error: ${error.message}`);
      return;
    }
    console.log(stdout);
  });
}
```

---

### 2. The Secure Approach: Use `execFile` or `spawn`

Instead of using `exec` (which spawns a shell), use `execFile` or `spawn`. These methods execute the binary directly and pass
arguments as an array, meaning shell metacharacters (like `;`, `&`, or `|`) are treated as literal strings rather than
commands.

```typescript
import { execFile } from "child_process";

function runSecurePing(userInput: string) {
  // Pass the executable separately, and arguments as an array
  // Even if userInput contains malicious symbols, they are safely passed as arguments to 'ping'
  execFile("ping", ["-c", "1", userInput], (error, stdout, stderr) => {
    if (error) {
      console.error(`Error: ${error.message}`);
      return;
    }
    console.log(stdout);
  });
}
```

---

### 3. Add Strict Input Validation (Allowlisting)

Even with safe functions, it is best practice to validate user input against an expected pattern (an allowlist) using regular
expressions before processing it.

```typescript
import { execFile } from "child_process";

function runValidatedPing(userInput: string) {
  // Define a strict regex for valid IPv4 addresses or domain names
  const ipOrDomainRegex = /^(?:[a-zA-Z0-9][-a-zA-Z0-9]*\.)+[a-zA-Z]{2,}$|^(?:[0-9]{1,3}\.){3}[0-9]{1,3}$/;

  if (!ipOrDomainRegex.test(userInput)) {
    throw new Error("Invalid input format. Potential command injection detected.");
  }

  // Input is verified, safe to proceed with execFile
  execFile("ping", ["-c", "1", userInput], (error, stdout, stderr) => {
    if (error) {
      console.error(`Error: ${error.message}`);
      return;
    }
    console.log(stdout);
  });
}
```

---

### Summary Checklist for Node.js/TS

- **Avoid** `child_process.exec()` with concatenated strings.
- **Use** `child_process.execFile()` or `child_process.spawn()` with parameter arrays.
- **Validate** input using strict allowlists or regex patterns before passing it to any system utility.
